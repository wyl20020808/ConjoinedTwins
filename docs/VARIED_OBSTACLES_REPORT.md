# 动态障碍、多通道地形与随机节奏调整

任务分支：`feature/varied-balanced-obstacles`，从已同步的 `dev` 创建。本轮不合并、不推送、不发布网页，当前线上仍是上一轮版本。

## 新增内容

| 内容 | 生产规则 |
| --- | --- |
| 往复横扫机关 | 周期 1.6 秒，横向往复 8 米；每段两台，纵向错开，提供同侧绕行空间 |
| 快速升降活塞 | 周期 1.8 秒，升降行程 5 米；压板、轴杆和横梁使用真实分部碰撞 |
| 双扫杆段 | 两根扫杆纵向错开 14 米，角速度 4.6 弧度/秒，低杆可跳、支座须绕行 |
| 双通道镂空桥 | 两条宽 2.2 米、长 22 米的单人通道，中心相距 4.8 米 |
| 三通道镂空桥 | 三条宽 2.2 米、长 22 米的单人通道，相邻中心相距 4.4 米 |

多通道桥复用真实道路切孔和云海，不是贴图假坑。每条通道分别进行脚底支撑和轻微回中辅助；两人可以前后同行，也可以各走相邻通道。绳长与身体间距约束不变，不能分走距离超出绳长的最外侧两条通道。

摆锤周期从 2.4 秒缩短到 1.8 秒，臂长从 9 米增加到 10.5 米，最大角度从 1.0 增至 1.12 弧度，锤头宽从 2.2 米增加到 2.6 米。完整横向摆动包络约从 17.35 米增至 21.50 米。支点同步抬高，最低点离地仍为 0.35 米。模型与碰撞共用参数；高速弧线扫掠加入角加速度上界补偿，新往复机关在每次折返时分割碰撞区间，防止只检测同侧端点而漏判。

## 节奏与密度

- 保留随机袋、种子复现、左右镜像及相位随机；选段时优先交错动态、地形、普通段，不再直接从完全洗牌的袋尾取走。
- 首轮踏板、接力和充能机关分别保留在第 4、8、12 段。五种新布局分散安排，在前 18 段内出现；没有为展示新内容把它们全部放到开场。
- 额外陷阱按难度最多 2/3/4 个，沿路段纵向分区并在区内小幅随机；每个位置独立尝试，前方受保护不能放置时，仍尝试后面的区域。不会把某处未放下的数量挤到其他区域补齐。
- 窄桥、新动态组合、接力段不额外叠加随机陷阱；门前、奖励、已验证双人路线及连线仍保留原有避让条件。模型预算、绳长、角色碰撞和验证断言未放宽。
- 三个随机变体均失败时，先用同一生产验证器验证简单绕箱段，通过后安装；全部失败仍保留原安全拒绝机制，不能为追求密度强行安装不可解布局。

这调整的是种类分布和空段回退，保留入场、归队、合作等待、起终点空间，不承诺每一米都有障碍。

同一生产验证器没有删除或减弱断言；`web_generation.gd` 只增加覆盖案例。曾在调试中运行中间版本回放，修订额外陷阱分区后停止过时回放并重新执行，历史日志保留但不当成最终版本证据。

本地日志及源码 SHA256 清单位于被忽略的 `build-tools/cache/varied-obstacles/`。不将测试日志、构建缓存或大文件入库。
