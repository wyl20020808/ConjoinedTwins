# Tripo 村庄环境与机关接入

日期：2026-10-19。任务分支：`art/tripo-village-integration`，起点为本地 `test@4485080`。

## 实际改动

八件 Tripo 文生模型已接入生产 `journey_boot.tscn` / `journey.tscn`，不只是放入资源目录。住宅改为民居与工坊，村庄增加道路外的院门和庭院杂物；森林路边替换苔石、枯木布景。石球换为包铁滚石；木制撞锤作为横向矮栏使用，按原危险体适配外形。铁球、机关数量、逻辑、速度、伤害、绳索和存档没有修改。

环境沿用现有 MultiMesh、空间分块和可见距离，不逐物体创建独立场景节点。机关模型进入原有分帧预读及邻域引用保留流程，石球绕自身中心随实际路程旋转。原来的碰撞尺寸与高度不变，模型适配碰撞；纯布景的完整包围盒保持在道路外。

保留已完成的 Forward+ 光照和现有材质，不对新资产覆盖统一纯色材质。每件一个材质、2K 颜色/法线/金属度粗糙度贴图，自动生成 LOD，内嵌纹理采用 Basis Universal 压缩。八件 GLB 共 41,486 三角面、25,781,924 字节；原件哈希及缩放参数记录在 `build-tools/journey/tripo-village-assets.json`。未覆盖旧模型。
