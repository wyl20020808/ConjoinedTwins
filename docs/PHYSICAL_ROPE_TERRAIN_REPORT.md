# 三维麻绳、真实地形与合作机关改造

日期：2026-10-15。任务分支：`feature/physical-rope-terrain`。生产入口仍为 `scenes/road_demo.tscn`，没有另建样板关。

## 实现

### 绳索

`rope_physics.gd` 使用 24 段三维质点链、XPBD 长度约束、柔顺弯曲约束、重力、阻尼及接触摩擦。绳长固定为 7.33 米，完整余量参与模拟，取消显示层缩短松绳的处理。自由段自然下垂，近全长采用张紧极限路径，消除有限迭代残留弯曲。角色位置仍须满足三维端点长度及绕柱拓扑约束；张紧会对队友施加有界牵引，所有角色修正继续经过实体扫掠。

`rope_solver.gd` 保留接触侧、绕柱拓扑、落地预留等既有规则。实际质点链用于工业机关、扫杆及迎面物绳段检测；`rope_view.gd` 只读取生产质点生成网格，没有第二套显示物理。圆柱、巨岩、绞盘和崖沿具有接触约束。道路缺口与悬崖外不提供地面，取消全局空气地板。粒子、前一位置及绑定状态纳入克隆、检查点、重定位与联机指纹。

撞击倒地时绳端先随腰部降低，0.65 秒后腰扣松开，自由端保留速度并落地。坠崖继续绑定，身体同时接受重力、地面和绳长约束，不通过固定延时让仍有支撑的身体穿过路面。救援保留原按键规则，吊挂身体加入重力、摆动、崖壁碰撞及收绳约束；爬上过程与绳端共用身体位置。身体倾斜和翻滚围绕腰部挂点进行。

麻绳使用程序生成的三股捻纹、纤维法线、粗糙材质和微小轮廓起伏；增加腰带、绳扣、绞盘、配重及绳响，移除绳身自发光。无需额外插件或下载。

### 地形及机关

`road_terrain.gd` 统一地面高度、支撑、法线、摩擦参数及平台运动查询。角色区分地面高度与跳跃高度，绳索读取同一地面。高于正常台阶的侧面需要跳上或等待平台降低，不能直接将角色抬上去；离开高台时进入下落。移动平台只携带站立角色，跳跃不继续附着平台。

`road_challenges.gd` 的 13 类内容直接进入现有三关随机池：

| 内容 | 生产关卡 |
| --- | --- |
| 弯折山脊、错位断桥、起伏坡面、连锁塌桥 | 第一关 |
| 分叉岛、石阶、倾斜桥面、横移浮台 | 第二、三关按池选择 |
| 升降平台、摆锤后接塌桥 | 第三关 |
| 交替喷口长廊、双人压板吊桥、麻绳绞盘桥 | 按各关目录递进分配 |

封路填充巨岩改为真实缺口；停止路线外随机散布陷阱。少量具有明确绕行目的的既有巨岩及已有机关保留。喷口缩短空档，长廊使用三排错位布置，按角色到达时间提前启动一次预热，增加预热烟、颜色反馈与多股渐隐喷流。压板与绞盘先开启吊桥，再等待桥面实际落平恢复推进；绞盘要求两人通过真实绑定的绳索持续张紧。三关仍保持固定推进镜头及共同终点。

随机目录保留明确教学与恢复区，避免同一关同时堆满全部内容。生产验证仍要求合法双人键盘输入、奖励可达、无护盾消耗、地面支撑与完整中央出口。移动平台等待单独计入验证预算；同步生成与后台生成一样可以尝试同类型变体，不取消无解检查。

生产入口按项目规则停用单人、人机自动输入和 M/F 切换；历史 AI 源码与旧测试保留。已有网络和触屏代码保留。

## 近似与边界

这是有界游戏物理，不是逐股麻纤维仿真。没有复杂打结、完整绳索自碰撞、磨损断裂或完整人体布娃娃；圆形绕障拓扑仍采用既有保守几何。当前绳长约束允许求解误差；松绳检查的总长伸长约 0.1%，实际渲染样本约 0–0.4%，快速死亡瞬态可能更高。救援仍是有限时按键机制，不是自由攀绳控制系统。地形为解析高度面，不支持同一水平位置的多层可行走洞穴。

体验验收仍需真人双人连续游玩，重点是牵引强度、桥头与石阶手感、喷口换位窗口、近景麻绳质感和组合难度。自动通关证明只说明存在合法路线。
