# 现代画面改造 · 第 1 步：光照后期与地图边界

日期：2026-10-19。分支：`art/modern-lighting-pass`（起点 `origin/test` 9e7b0e8）。

## 改动

- **渲染器分档**：桌面/Mac 改用 Forward+（Mac 走原生 Metal）；`.mobile` 与 `.web` 通过项目设置覆盖保持 Compatibility，网页与 iOS 行为不变。
- **画质层** `scripts/journey_atmosphere.gd`，仅 Forward+ 启用：
  - AgX 色调映射，曝光 1.05；环境光改由天空提供（天空占比 0.7）。
  - SSAO 加 SSIL 屏幕空间间接光，柔光模式泛光，调色（对比度 1.12、饱和度 1.12）。
  - 雾色取自同方向天空（aerial perspective 0.75）。
  - 体积雾按林地权重变化，密度 0.0012 到 0.0035。
  - 阳光阴影改用固定模糊 1.8，不用 PCSS 角直径，避免影子边缘出现颗粒噪点。
  - 远景轻微景深：95 米外开始虚化，强度 0.05。
  - 直射光与环境光分别乘 1.6 和 1.15，补回 AgX 压低的亮度。
- **地图边界**（所有渲染器均启用）：跟随镜头平移的地平线环带（半径 118 米到 2400 米），加两层不受雾影响的远山剪影（半径 640 米、1150 米）。
  - 悬崖段：环带降到 −42 米，作为云海。
  - 林地与村庄：环带作为远方原野。
  - 林中：远山同步淡入雾色，不会在雾墙上方露出清晰剪影。
  - Forward+ 下镜头远裁剪面放到 2600 米。区块加载窗口不变，不增加实际模型数量。
