# 单人搭档避障与摆锤调整

基线：本地 `test` 的 `f7e4cf8`。任务分支：`fix/buddy-obstacles-pendulum`。

## 实现

- 修正复合机关的避险预测：使用实际运动部件及各自高度，不再将无碰撞轨道、空中横梁和升起的锤头合并成从地面到顶的实体墙。这是横跨道路的往复撞石处搭档停住的直接原因。
- 危险预测延长为 0.65 秒、八段采样；真人移动意图保持短期外推，避免将被门挡住的真人误判为持续向前运动，从而破坏双人门的配合。持枪搭档按实际减速预测位移。
- 旋转扫杆、跳杆、周期地刺复用生产连续碰撞与阶段边界检查；摆锤预测加入生产碰撞同类的弧线误差补偿。
- 固定高柱、巨石阻路时，先横移到可通行边缘再前进；候选路线考虑地面、绳长及真人占位。颜色门墙体继续交给专用对门逻辑。
- 摆锤居中，摆臂从 210 增至 360 单位，支点同步从 235 升至 385 单位，保持最低点锤头底部离地 7 单位。锤头最大横向覆盖约 350 单位，超过道路半宽 320；摆至两端抬高后仍可从下方通过。显示与生产碰撞共享参数。
- 仅降低道路摆锤音量：挥动声从 +1 dB 改为 -9 dB，机械循环声从 -8 dB 改为 -18 dB。其他机关及 Boss 音效保持原值。

所有移动继续通过普通方向、跳跃输入及原有碰撞、地面和绳索求解，不增加瞬移、无敌或额外速度。
