# 画面质感第四刀：界面视觉语言、世界标签降噪与受击反馈

日期：2026-10-19。分支：`art/lookdev-ui`（从第三刀 `art/lookdev-ground@7b93ff9` 继续，前三刀尚未合入 `test`）。

## 问题

环境、光照和路面处理之后，画面里最像"原型"的是界面：

- 按钮、面板、输入框全部使用 Godot 默认主题，开始页和暂停页是浅灰细条按钮，和场景资产没有共同语言。
- 左上血条是两块无底色的细条，右上武器面板一大片空白，暂停按钮是两条手绘竖线。
- 敌人血条是 3 米宽的亮绿色方块，满血也常驻，世界内元素过多。
- 受击和低血量没有任何画面反馈。

## 改动

### 统一的界面语言

`scripts/journey_view.gd`：

- 新增 `glass_style()`：深色玻璃底、细暖金描边、圆角、投影，HUD 与菜单共用。
- 新增 `style_button()`：主按钮暖金实心、其余暗色玻璃；统一的悬停/按下/禁用态和字号。
- 开始页、暂停页、失败页使用同一套面板，标题 38 px、正文 16 px；面板高度跟随内容，不再固定 360 px 留出一大块空板。
- 模式、难度、联网按钮改为紧凑胶囊；网络地址输入框也换成玻璃底。
- 暂停按钮改为圆形玻璃底，保留原来的两条竖线图标。

### HUD

- 左上生命面板：玻璃底板 + 圆角血条（深色轨道、柔和描边与微光），01 青、02 琥珀；两名角色之间加细分割线。
- 右上武器面板：玻璃底板，新增"武器"小标题，弹药字号加大，换弹/耗尽提示保留。
- 角色色与 3D 脚下的光环一致，联机交换视角时同步交换。

### 世界标签降噪

`scripts/journey_enemy_view.gd`：

- 敌人血条从 3.35×0.26 收到 3.35×0.26 / 填充 3.2×0.13，颜色改为柔和的苔绿、沙金、砖红。
- 满血且未被锁定时不显示血条；被锁定或刚受击 1 秒内才出现，减少世界内常驻条状元素。

### 受击反馈

新增 `scripts/journey_vignette.gdshader`：

- 一层全屏透明 quad，放在 CanvasLayer 0（HUD 在 1），只压 3D 画面，不压界面。
- 平时是轻微暗角；受击时红边快速亮起、约 0.4 秒衰减；低血量时红边常驻并随血量加深。
- 只读取同步后的真实血量，不采样屏幕纹理，HUD 与后处理都保持低成本。

## 未验收

- 没有真人试玩。HUD 在明亮天空下的对比度、红色受击边缘的强度、暂停页的阅读顺序都需要实机确认。
- 手机竖屏只跑了布局用例，没有实际截图检查触屏按钮与 HUD 的遮挡。
- UI 没有过渡动画；伤害数字、暴击、护盾破裂等更细的反馈留到后续。
- 只在 M4 / Metal / 720p 测过；网页与 iOS 未运行。
- 没有使用 Blender、Tripo 或互联网新素材。
