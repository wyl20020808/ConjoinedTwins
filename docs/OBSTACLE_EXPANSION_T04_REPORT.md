## 实际改动

修改 `scripts/industrial_obstacles.gd`、`road_run.gd`、`road_templates.gd`、`road_demo.gd`；新增 `tests/obstacle_expansion_t04.gd` 和 `tests/obstacle_expansion_t04_scene.gd`。更新 README、初期开发方案和障碍扩展设计。资源为工程内程序模型，未导入新外部资产。

巨锤柄长 180 单位，预警、下降、摆动、上升、抬起窗口分别为 2.4/0.45/4/0.7/4.2 秒。柄按实际方向盒检测，同步插值实际绳段；时间切片带最大运动包络。锤头完全离路但柄切中绳段的反例保存于专项证据。教学锤架中心在段内 y=448，完整包络退出后 y=650 回中，满足困难第三关 208.8 单位/秒下的合法横移出口容差。流式回收依据完整摆动包络，避免抬起姿态提前移除仍可能扫回的危险。

塌陷板是 160×60 单位局部道路。第一次实际地面踩踏触发，裂纹 0.75 秒后进入退出宽限；总宽限为 `(60+24+146.6)/当前关速+0.35` 秒。首次触发后双方后续踩踏、跳跃均不重置。塌后真实移除脚底支撑并切除道路顶部，重试和复用恢复板面。计时承诺针对获准入口后的正常前进，不承诺主动倒退或驻足仍能在截止前通过。

蒸汽两个喷口相位差 3 秒，周期为预警 2.4、升压 0.4、喷射 0.8、消退 0.3、安全 2.1 秒。喷流顶部随消退缩小，非喷射阶段高度归零；脚底均安全但绳段跨喷口时共同失败，护盾不能消除割绳。三类教学均有固定同侧连续旁路。

第一关保留滚球首段，再将新增独立教学置于重复练习前，确保 100 秒关长内出现；其他关在两种球和火箭基础教学后进入新增内容。新增教学后优先保留高柱、低空及身体高度类型，再放重复左右练习。保留 t01 已验收的手动速度 160、基础关速 140/160/180、关号倍率 1/1.08/1.16、跑动动画提速、跳跃与绳长参数。本轮不实施 t05 的组合与增密。
