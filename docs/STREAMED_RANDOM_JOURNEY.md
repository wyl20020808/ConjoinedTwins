# 连续旅程：局部驻留与受控随机生成

任务分支：`fix/streamed-random-journey`，从完整玩法整合后的 `test@a0840a6` 创建。机关、动物冲撞、追击、弓手、狼、双滚球、窄路、救援与透明 HUD 均保留。证据位于工程外的 `D:/ConjoinedTwins-task-temp/streamed-random-evidence`。

## 降耗方式

- 整章保留机关、怪物及存档的逻辑数据，不按画面距离删除玩法。展示窗口为前方 120 米、后方 30 米；提前 40 米分帧准备，额外 20 米保留迟滞，越界卸载节点。环境区块保留当前邻域，减少尚不可见的整片森林实例。
- 机关与动物资源按邻域请求和保留。合作门离开窗口后回收；终点不再从开局一直持有模型。静止动画姿态不重复播放、定位、暂停。
- 静态实体与地形分桶在布局变化时重建，运动物体更新自己的分桶。静态缺口复用几何，仅重新采样会塌陷的部分。倒树、重试、读档和地图替换仍触发失效。
- 精确物理查询使用玩家、完整绳路与运动扫掠的保守范围，不能以“模型不可见”作为取消碰撞的理由。高速弹体、滚球挂绳和运动机关仍保留连续检测。
- 飞行物预警使用全路宽换侧时间与最高合法接近速度推导保守窗口；已锁定或尚不可能锁定时省掉重复精算，无侧向出口的自定义威胁仍走完整逻辑。
- 保留 120 Hz 固定模拟、三个运动子步和既有绳索精度；没有增加设备专属启动参数。

## 随机生成的含义

此前连续旅程主要按 `n % 类型数` 循环，生产场景也没有开启换种子。现在生产构造直接启用随机种子，机关和敌人分别使用独立的局部随机流。测试默认固定种子；联机沿用共同种子的确定性流程；从存档继续恢复原地图。

- 机关类型、组合形态、左右侧、窄路形态、飞行波次、滚球种类、地刺相位和怪物站位使用洗牌抽样。种子变化时布局变化，同种子完全可复现。
- 每四个怪物群的计划数量为 `3、4、4、5` 的随机排列，目标均值为 4；群组位置在原锚点前后最多 6 米扰动。实际数量继续受实体、缺口与合作门安全检查约束。
- 机关池按原有权重抽完一袋再洗牌，避免纯独立抽样导致某种机关长期缺席；窄路替换的拍子不消耗主机关配额。
- 保留三拍共享安全侧、合作门留白与组间至少 20 米换侧空间；只对组内中拍做零均值的小幅位置扰动。随机性不包括破坏这些通行约束。合作站位置仍按原关卡安排。

## 验证方式与边界

`python build-tools/check_journey_performance.py` 串行执行 23 组检查，新增随机分布、驻留窗口及预警窗口对照。原有 CPU、资源增长门槛不放宽。固定节拍断言改为允许组内明确的 ±18 道路单位扰动，换侧最小间距保持不变；生命周期比较等待整个预热窗口完成。

随机分布检查覆盖 12 个种子 × 三章，并检查生产新种子、固定种子重试、存档恢复、实际出生安全和配比。资源巡检固定种子，避免将不同地图的节点数量当作泄漏。

CPU 对照使用相同的新地图、输入和固定步，交错运行旧缓存实现与新实现，并逐步比较完整状态指纹。人工移动到中途的位置可能死亡；死亡后的空转样本不能用于性能结论。原生渲染另运行 16 轮救援循环；退出泄漏或错误不得算作通过。

本地试玩入口为本任务工作区的 `启动归航Demo.cmd`，运行 `scenes/journey_boot.tscn`。尚未合并到 `test` 时，主目录入口仍是上一版本。本轮后台检查不代表用户真实输入、其他设备帧率或可见画面验收。

## 当轮结果

- 最终串行门槛 `gate-production/summary.json`：23/23 通过，测试期间源码哈希未变化。包括 4480 项随机生成检查、796 项驻留/缓存检查、5000 项预警窗口对照，以及原有碰撞、追击、战斗、救援和资源生命周期检查。
- 36 份固定种子地图的怪物数量：第一章均值 119.33，范围 114–126；第二章均值 97.58，范围 93–102；第三章均值 97.17，范围 91–102。该样本标准差分别为 3.75、2.93、3.41；实际数量受出生安全过滤影响，不承诺每局严格相等。
- `cpu-compare-final.json`：九位置共 1080 个固定步逐步状态一致。三个开局均持续运行，单固定步 CPU 中位数由 3.493 / 6.375 / 6.308 ms 降至 2.780 / 5.219 / 5.074 ms，分别下降约 20.4% / 18.1% / 19.6%。另外两个持续运行的中途样本约下降 17%；四个最终失败的人工跳转样本只用于状态等价，不计入性能结论。每个静态布局仅建立一次实体空间索引。
- 流式展示阶段的独立同内容对照（尚未更换随机编排）：`before-residency.json` 与 `streamed-residency.json`，节点 1809 → 1072，180 次展示更新总 CPU 441.44 → 320.12 ms，约下降 27.5%。这组数字隔离了驻留窗口的收益，不把随机地图之间的差异算作优化。
- 完整生产入口 CPU 回归：180 个画面循环内 228 次物理回调，双固定步模拟平均 11.84 ms，展示每帧一次，原门槛通过。这是后台回归测量，不是实际 GPU 帧率结论。
- `native-final/summary.json`：原生 ANGLE 渲染 16 轮救援循环通过，退出码 0，错误与泄漏诊断为空，源码未变化。本次约 64 秒、2944 个采样帧的帧间隔中位数 16.666 ms、p95 24.277 ms、最大 394.558 ms。仍存在长帧；不能据此声称所有卡顿已消除或所有设备稳定高帧率。历史原生崩溃证据继续保留，一次 16 轮通过不能证明其根因已彻底消除。
- 执行者自测与本轮源码审查完成；Controller 独立测试未运行（`tests=[]`），用户真实输入和可见试玩待验收。主工作区原有未提交文件、其他分支与运行进程未改动。
