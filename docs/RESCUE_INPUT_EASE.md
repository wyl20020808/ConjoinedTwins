## 调整

玩家反馈原救援需要疯狂连按。本轮降低频率要求，并留出反应和松手间隔：

| 参数 | 原值 | 新值 |
| --- | --- | --- |
| 拉满限时 | 3 秒 | 5 秒 |
| 每秒进度回落 | 0.4 | 0.15 |
| 简单 / 普通 / 困难频率参数 | 4 / 5.5 / 7 次每秒 | 1.25 / 1.5 / 2 次每秒 |
| 同关每次救援的难度倍率 | 1.15 | 1.0，不再递增 |

频率参数是拉人者在限时内完成的理论门槛，实际验收为普通难度每秒按两次，并先留一秒反应时间。仍需按下再松开，长按不自动积累；被救者可同步按跳跃协助，效果仍为拉人者的一半。队友必须站稳、落脚点必须真实安全，原爬升动作、绳索和回镜逻辑沿用既有实现。
