# 特效第三刀：战斗手感

日期：2026-10-20。分支：`feature/fx-hazards`（接第二刀 `a53f7ac`）。

## 改动

- **枪口焰**（`journey_combat_view.gd`）：原来的发光方块换成两片十字交叉的加色火焰面片，再加一片朝后的星形；每次射击随机旋转、缩放 0.8–1.25 倍。原有枪口暖光保留。
- **曳光**：弹道半径 1.8 → 3 厘米，自发光 1.2 → 4.0，在 Screen 晕光里会晕开。
- **抛弹壳**：每人一个持续发射器，每次开枪开 0.05 秒，从枪右侧抛出黄铜弹壳，带旋转与重力。
- **命中碎屑**（`journey_enemy_view.gd`）：原有火花之外，按怪物溅出碎屑——树精木屑、石卫石粉、狼灰毛，其他怪物溅土色。
- **死亡余烬**：原有尘爆与冲击环之外，身体中段和上部各炸一团青橙能量碎片。
- **攻击预警**：怪物预警阶段叠暖红边缘光（新增 `scripts/enemy_charge.gdshader`），强度随蓄力进度上升并脉动；命中闪白优先显示。只亮轮廓，不把整只怪物染红。
