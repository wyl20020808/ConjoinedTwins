# 第二轮画面 · 第六刀：打击与拾取特效

日期：2026-10-20。分支：`art/impact-fx`（从第五刀 `art/ground-water@42360bf` 继续）。

## 问题

第一轮已经有命中闪白、伤害数字和小簇火花。但怪物倒地只扬一小团尘土，玩家受击只有屏幕红边，拾取物离远了就看不见。镜头按设计不能晃动，冲击感只能靠光、粒子和画面后处理来补。

## 改动

- **冲击波环**（新增 `scripts/journey_shockwave.gdshader`，`journey_fx.gd: impact`）：
  - 贴地加色圆环，0.42 秒内按缓出曲线扩散到目标半径，前 20% 时间带一层内圈冲击光；
  - 每次冲击同时触发一簇火花和一盏 0.22 秒衰减的补光；
  - 6 个圆环、3 盏灯固定轮换，逐帧推进；网页与移动端不建补光。
- **怪物倒地**：原有尘爆之外，加一次 3.2 米的暖橙冲击（补光 3.5）。
- **玩家受击**：生命值下降时，在受伤一方脚下打一次 1.8 米的红色冲击（补光 2.6）。
- **屏幕边缘色散**（`journey_vignette.gdshader`）：受击闪红期间，画面边缘做 RGB 分离，强度随原有 `damage` 衰减；`damage` 为 0 时不采样屏幕纹理，平时没有额外开销。
- **拾取物光柱**：6 米高、无盖、自下而上渐隐的加色光柱。弹药与冲锋枪为金色，医疗为绿色，远处一眼可见。

以上都只读模拟状态，不改伤害、拾取或判定。

## 没做的

- **命中顿帧**：要改 `Engine.time_scale` 或暂停固定步，会影响 120 Hz 模拟、联机与既有时序测试，属于逻辑层改动，本轮不做。
- **机关落地冲击环**（压机、撞锤落地）：要从各机关的相位采样里识别"落地瞬间"，留待下一轮。
