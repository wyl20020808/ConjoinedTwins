# 开门、短缺口救援与开局预加载修复

任务分支：`fix/gate-rescue-preload`。本次仅修改源码、专项测试与说明，未合并、推送或导出测试包。

## 修改内容

- 充能绿区每侧宽度从 0.95 米扩大为 2.1 米，内缘间距满足新的 70% 张力门槛；接收半径从 0.4 米扩大到 1.5 米，覆盖绿区纵深。仍要求真实绳路、有效高度、无障碍遮断、连续充能 0.8 秒。
- 同步踏板半径从 0.9 米扩大到 1.3 米，仍要求两人分别落地站板 0.35 秒。场景接收器、绿区、踏板共用判定参数。
- 救援原先只抽查未来路径上的五个点，短缺口可能落在两个采样点之间。现在对完整线段与缺口边界求距离，连同角色半径和余量检测，并检查前方实体阻挡。搜索范围扩大至绳长内，不能隔着实体放置落点；去掉未经完整检查的旧落点兜底。如果确实没有合法落脚点，按坠落失败处理，不返回假安全位置。原有爬上动画、冻结世界与输入保护保留。
- 开局、整关重试、跨关及存档恢复先准备前方四段，再消费游戏帧。加载条反映已完成的证明数量，证明完成后仍可显示场景准备阶段。模型逐个准备，加载期间不推进角色、计时或随机抽签序列。加载计算每次最多 256 步且以 6 毫秒为软预算；游戏中恢复原有每次 32 步、2 毫秒预算，持续维护前方四段。单步本身不能中断，因此不是严格的帧时上限。
