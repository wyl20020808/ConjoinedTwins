# 特效第一刀：机关

日期：2026-10-20。分支：`feature/fx-hazards`（从 `test@40e8a1d` 新建，独立 worktree `ConjoinedTwins-fx`）。

## 改动

新增 `scripts/journey_hazard_fx.gd`，挂在 `sync_static_hazards` 的每个可见机关之后。它只读模拟采样（阶段、位置、尺寸），在阶段切换时触发一次性特效，运动中的机关挂持续拖尾。一次性特效复用 `journey_fx` 的冲击环、火花、尘爆。

| 机关 | 触发 | 特效 |
| --- | --- | --- |
| 压机 | 进入"压住" | 冲击环、四角尘爆、四周飞出碎石、短促补光 |
| 地刺 | 进入"弹出" | 碎土、金属火花 |
| 坍塌路面 | 开裂、坍落 | 开裂掉碎屑；坍落时大片碎石、尘爆、冲击环 |
| 摆锤 | 开始摆动 | 底部扬尘 |
| 蒸汽口 | 加压、喷射 | 加压时扬尘；喷射时粒子蒸汽柱，覆盖喷口宽度并带湍流 |
| 滚石、铁球、木桶、飞石 | 实际移动时 | 地面扬尘拖尾 |
| 火焰弩 | 飞行、结束 | 加色火舌拖尾加随行暖光；结束时火星与冲击环 |

- 蒸汽口原来的喷流锥体（贴图失真）每帧隐藏，改由粒子表现；碰撞与采样不变。
- 拖尾按真实位移判断：预警阶段采样也标为 active，但物体还没动，不出拖尾。
- 对象池：碎石 6、蒸汽柱 4、拖尾 8。离开显示窗口的机关当帧归还拖尾。网页与移动端粒子数减半，不建拖尾灯。

## 验证

- 新工具 `builds/fx/tools/fx_scrub.gd`：不跑物理，只推进模拟时间并手动设置机关触发时刻，在指定时刻拍特写。截图在 `builds/fx/s-*`（本地）。
- 另有 `fx_watch.gd`：真实模拟下按特效池事件截图；实际运行中人常被坑和机关判负，只拍到了滚球和木桶拖尾。
- `check_journey_performance.py` 26 项通过；生产入口 headless 退出码 0。
- M4 1080p（冷机）：森林 13.1 ms、村庄 8.7 ms、矿道 7.1 ms、设施 7.0 ms。

## 未验收

- 火焰弩、滚球需要玩家靠近才发射；时间推进工具拍不到它们飞行的样子，只确认了真实运行中滚球、木桶有拖尾。
- 地刺的弹出瞬间没有拍到。
- 没有真人试玩。
