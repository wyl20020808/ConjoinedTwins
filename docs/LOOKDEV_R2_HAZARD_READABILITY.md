# 第二轮画面 · 第七刀：机关可见度（黄昏顺光 + 夜间头灯）

日期：2026-10-20。分支：`art/hazard-readability`（从第六刀 `art/impact-fx@b38b1e2` 继续）。

## 问题

用户试看截图后指出：时段光照改完后，机关可见度变低，黄昏段最严重。截图核对后的原因：

1. 黄昏主光是侧逆光（yaw 112°、俯角 13°），机关朝镜头的一面整体处在背光里；
2. 木石机关、红褐路面、橙色主光同一色相，几乎没有色差；
3. 低角度长影铺满路面，机关落在阴影里；
4. 夜里机关只靠月光、火把和头顶小灯，前方十几米外基本是暗的。

## 试过并放弃的方案

| 方案 | 结果 |
| --- | --- |
| 菲涅尔冷白轮廓光（叠加在机关网格上） | 机关多是平面方块，整面被染成冷白，像冰块，用户否决 |
| 屏幕空间细描边 | 只写了代码，没做截图；描边偏卡通，与写实光影不搭，没有采用 |
| B 冷色阴影（蓝紫补光与环境光） | 对照图里变化最轻，用户未选 |
| C 预警片 HDR 自发光（红/亮奶白斜纹） | 对照图里提升有限，用户未选 |

对照截图见 `builds/round2/variants/sheet-farm.png`、`sheet-river.png`（本地）。生成工具是 `builds/round2/tools/variants.gd`。

## 采用的改动（用户选择：A 顺光 + 夜间头灯）

- **黄昏顺光**（`journey_atmosphere.gd`）：第二章主光改到镜头侧后方（yaw −38°、俯角 17°）。
  - 光色、强度、天空晚霞配色不变；
  - 机关与角色朝镜头一面被照亮，影子朝远处倒，不再盖住机关；
  - 代价是没有了逆光剪影感。
- **夜间头灯**（`journey_view.gd: sync_hero_lights`）：第三章两人各绑一盏朝前的聚光（01 冷白、02 暖白）。
  - 头部高度、对准前方 9 米处地面，射程 22 米、张角 32°、能量 10；
  - 不投影，写入体积雾，形成可见的光束；
  - 原有头顶小灯保留，用来照亮角色自身与绳索。白天不创建。

都只改光照，不改机关模型、颜色、碰撞与判定。
