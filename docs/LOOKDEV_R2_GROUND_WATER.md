# 第二轮画面 · 第五刀：河面、草地与远景原野

日期：2026-10-20。分支：`art/ground-water`（从第四刀 `art/night-mine@a8b0acb` 继续）。

## 问题

- 第二章“河岸 / 水车”段从来看不到水：两侧整块地面（顶面 y = −0.15）压在水面盒（y = −2.2）上方，水被完全盖住，水车像立在空地上。
- 第二章路外是成片纯色平地，只有零星松树和高草。
- 远景环带是单色平面，黄昏时像一块平板。

## 改动

- **河道**（`journey_chunk_plan.gd`）：河岸段右侧拆成三部分：
  - 近岸 3 米；
  - 26 米河面（路缘外 19–45 米，水面低于地面约 0.6 米，下方是碎石河床）；
  - 远岸。
  右侧松树挪到远岸，灌木只留在近岸；左侧与水车、河岸房屋位置不变。
- **水面着色器**（新增 `scripts/journey_water.gdshader`）：
  - 三组解析波纹法线，顺流朝镜头流动；
  - 菲涅尔、深浅水色、贴岸 1.2 米的白沫，顶点轻微起伏；
  - 不做折射和屏幕空间反射，反射来自天空辐照度与主光高光。黄昏段能映出橙粉色天空。
- **第二章草地**：每个区块约 500 株风动草（每株约 32 面）和少量灌木，用 MultiMesh 批量绘制，避开右侧河面与农田垄。绘制距离沿用第一刀的林下层 75 米。河岸段两侧地块改用道路地形材质。
- **远景环带**：按世界坐标三平面采样一张大尺度蜂窝噪声色块（田块与林斑）。环带随镜头平移，纹理不跟着走，时段压色照旧。
