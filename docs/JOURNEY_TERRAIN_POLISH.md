# 旅程地形、后退与表现改进

2026-10-15。起点为拉取后的远端 `test`（`3ee7185`），任务分支为 `feature/journey-terrain-polish`。本轮保留当前生产版本的单人搭档、本地双人、远程联机、战斗训练和触屏入口。未合并、推送或发布。

## 行为变化

1. **角色后退**：W/S、↑/↓ 与触屏摇杆使用完整纵向输入。后退下限为 `max(0, 镜头累计进度 - 200)`，即 10 米；地图世界坐标不动，镜头进度仍取历史最高值。后退遵守实体扫掠、地面缺口、角色间距和绳长约束，不瞬移穿越障碍。搭档只在玩家主动后退时跟随后退，避免前进中退回刚绕过的断口。
2. **更密集的组合路段**：主节拍由 20 米缩至 15 米。三章主机关点为 95 / 76 / 76，另在主机关之间组合偏侧断路、阶梯崖沿、碎石与石柱、台阶与横木。三章物理机关数量为 264 / 205 / 217，合作门仍为 7 / 5 / 5。三拍共用安全侧，换侧前留出横移空地；门前后保留站位与退出空间。没有增加不可跳越的全宽必死缺口。
3. **画面**：Blender 生成紧凑叶簇树冠和 LOD，减少亚像素叶片；既有扫描贴图继续用于地面、石柱和横木。真实缺口增加有厚度的岩壁和随深度变暗的断面。路面增加车辙、潮湿土斑与铺石缝；补充人物的环境光，降低天空能量，保留固定镜头方向。
4. **换弹**：枪身抬起并侧倾、弹匣抽出及插回、拉栓归位；双臂使用两段骨骼解析定位，腿部继续播放原来的移动与跳跃动画。所有阶段来自 `weapon.reload`，没有独立 Tween 或墙钟时间。暂停、自动换弹、丢枪与重试共用模拟状态。

联机协议从 4 升至 5。后续部署时网页、原生客户端和中继须一起更新；本轮没有修改运行中的服务。

## 有限性能优化

- 远处扫杆先用新旧完整绳段的保守包围盒排除，再执行原来的高度、圆弧和连续扫掠；没有降低物理频率、迭代次数或碰撞精度。
- 地面缺口按 20 米纵向区间索引，每个模拟时刻保留至多 16 组查询；类型索引每固定步只计算一次哈希，重试和存档恢复时失效。
- 拾取物一次建立可见集合，清理离开窗口的展示节点，替代重复全表查找。
- 桌面与 Web 共用按空间分组的 MultiMesh；第二、三章的碎片地面合并为两个网格，减少节点。
- 单棵橡树近景三角形从 9,720 降至 1,376（约减少 86%），远景从 2,332 降至 596。六份新资产合计约 262 KiB，旧资产保留。

同一密集关卡、相同静止输入、完整生产固定步的本机 headless 对照（Apple M4，Godot 4.7.1，预热 30 步、采样 180 步）：

| 章节 | 优化前中位数 | 优化后中位数 | 降低 |
| --- | ---: | ---: | ---: |
| 穿林入村 | 5,886 μs | 3,994 μs | 32.1% |
| 水车河道 | 5,332 μs | 3,463 μs | 35.1% |
| 矿道归航 | 5,413 μs | 3,563 μs | 34.2% |

对照副本位于忽略的 `build-tools/cache/polish-reference/`：保持密集布局，使用优化前的缺口、地形与扫杆查询。使用 `python3 build-tools/journey/compare_polish_cpu.py` 可重建对照并复测。最终记录为 `build-tools/journey/evidence/polish/cpu-comparison.json` 与两个 `cpu-*-final.log`。这是有限 CPU 采样，不是手机帧率、GPU 性能或压力测试。最早一次场景计时因缺少导入缓存而无效，没有用于性能结论。

- `journey_sweeper_bounds.gd`：900 组随机对照，包含 404 组命中，优化前后结果一致。
- `journey_combat.gd`：71 项通过；`journey_scene.gd`：18 个章节区域检查通过，场景节点最高 1,968。
- `journey_combat_online.gd`：421 个共同帧一致，验证真实 WebSocket 双客户端后退、镜头进度、射击、换弹、丢枪、暂停和重试。退出仍有 ObjectDB / 资源回收警告，不能宣称零警告。

三章完整合法输入回放全部到达结算：25,344 / 20,318 / 23,779 个 60Hz 输入帧，7 / 5 / 5 道门全部打开，双方生命均为 100，最大绳长分别为 146.600 / 146.233 / 140.793 单位（上限 146.6，即 7.33 米），镜头最小位移均为 0。第三章输入夹具会停步等搭档，避免领跑者先进入下一处断口；三章均未修改位置或跳过机关。记录为 `campaign-0.json`、`campaign-1.json`、`campaign-2.json`。路线输入夹具新增“敌人消失后仍避开对应静态组合”的判断。旧“角色绝不后移”断言根据本轮后退需求改为“镜头绝不后移”，保留通关与绳长检查，并增加全门开启及双方存活检查；测试不会修改角色坐标、生命或机关状态来通关。
