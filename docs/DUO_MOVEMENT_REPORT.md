- `scripts/road_run.gd`：主玩法删除 AI 及模式 API，统一 120 Hz 固定步；双方归一化四向输入、自动推进、独立有界前后位置、跳跃边沿触发与重力。地面连接包含前后差，最大 220 单位；子步线段碰撞结合跳跃底部高度，任一人碰撞共同失败。重试恢复位置、高度、输入和计时。
- `scripts/road_demo.gd`：01 WASD / 空格，02 方向键 / 回车；删除模式按钮，开始、暂停恢复及重试屏蔽旧按键至释放。固定相机调整为位置 `(0,11,21)`、FOV 58。角色横向中心范围从 ±156 扩大到 ±234 单位，即 1.5 倍；路面宽 24.6 米，栏杆、灯柱、建筑、地台和拱门同步外移/加宽。
- George / Leela 原有骨骼资源直接复用，动画名称实际为 `HitRecieve_1` 和 `HitRecieve_2`，本次使用前者。接入 Idle、Run、Jump、HitRecieve_1、Death 与基础混合过渡；移除滑行底座，保留识别灯；地面投影阴影反映腾空，三维连线随角色高度更新。
- 更新 AGENTS、README、方向说明和初期方案中的当前要求；历史内容保留并标注。当前验证 cmd 指向新的生产场景测试。原 AI 测试及截图入口作为历史文件保留，不冒充本轮验证。
