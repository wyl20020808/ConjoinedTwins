# 画面质感第三刀：路面细节、路缘填充与 60 帧余量

日期：2026-10-19。分支：`art/lookdev-ground`（从第二刀 `art/lookdev-lighting@4eb0a0f` 继续，前两刀尚未合入 `test`）。

## 问题

镜头和光照解决后，画面里面积最大、最经不起看的是路面：

- 2×4 米铺装贴图镜像平铺，近景能看出同一块石板重复；整条路明度均匀，没有车辙、湿痕和水洼。
- 路缘是一条 16 米的几何直边，铺装和草地的交界生硬；17–20 米的空地几乎只有草。
- 第二章之后森林段帧时间在 17–18 ms，已经超过 60 帧预算。

## 改动

### 程序噪声与路面材质

新增 `assets/landscape/ground/road_macro.png`（512×512，约 306 KB，FFT 周期噪声，非外部素材）：

- R：29×43 米尺度的大色调变化，打散 2×4 米铺装的重复。
- G：中尺度细节，用于粗糙度扰动和路缘边界推拉。
- B：稀疏水洼（约 8% 面积）。

`scripts/journey_ground.gdshader`：

- 铺装切片从 2×4 米改为 2.8×5.6 米，重复频率降低约三分之一。
- 大尺度明度变化 ±10%，粗糙度随中尺度噪声变化。
- 水洼：压暗约 15%、粗糙度降到 0.30、法线压平，给雨后路面一点反光层次。
- 主车道（|x|≈4.6 米）轻微压暗、磨亮，和路肩分开。
- 路缘边界用中尺度噪声推拉 1–2 米，不再是一条直线。

纹理导入使用无损、生成 mipmap、关闭 3D 自动压缩，避免远处噪点和块状压缩。

### 路缘

`scripts/journey_landscape.gd`：

- 路缘草簇：铺装面最后半米内按坐标散列放置 `grass`，打碎 16 米直边；用 1.7 米安全框检查，不跨缺口。
- 路缘生活带：17–19.6 米空地按 6.6 米间隔放置木桶、倒木和苔石，遮住道路与草地的硬接缝。

### 性能

- 关闭 SSIL。实测森林段 SSIL 约 1 ms，只提很轻的间接色；同一组截图对比观感差异很小。
- 新增大尺度噪声只多一次线性采样，并把过滤从各向异性降为线性 + mipmap。

## 未验收

- 没有真人试玩。水洼是否可读、车辙是否影响危险可读性、路缘道具是否挡视线，需要用户实机确认。
- 水洼在明亮日光下比较克制，截图里更像湿痕而不是镜面；如果要加强，需要单独做反射/粗糙度对比。
- 铺装仍是同一种石板图案，只降低了重复频率；真正不重复需要更大尺寸或分区贴图。
- 只在 M4 / Metal / 720p 测过；网页、iOS 和 Windows 未运行。路面材质在 Compatibility 下也会多一次采样，需要看网页帧率。
- 没有使用 Blender、Tripo 或互联网新素材；下一刀（界面与地标）再决定是否生产。
