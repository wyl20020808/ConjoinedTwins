## 危险、合作与恢复

- 倒树：先摇晃和标记倒伏范围，再倒下；砸落阶段有伤害，落地后保留实心树干碰撞。
- 坍塌林道：角色踩踏触发裂纹，宽限后变成真实缺口；侧路仍能通过。角色、绳索与显示共用已有地形规则。
- 野猪：预警后沿锁定路线冲锋，四条腿有独立动画通道，躯干有起伏。攻击不追踪改道。
- 村民：投掷动作对应固定落点，推车动作与车体移动同步；村民从推车出发侧跟随，避免从另一侧瞬移。
- 水车机关：沿明确包络横扫，模型、提示与攻击相位读取同一生产时间。
- 组合段：最后区域安排投掷与推车的组合，出口机关前保留攻击结束及调整站位的安全距离。
- 出口：先供能、再双人站板，门开启后锁存；吊桥放平后才提供真实支撑。桥板延伸到两端岸上，覆盖角色脚底半径需要的接缝余量。
- 单向站位：供能装置与踏板前设置可横移的停步位置，避免越过操作区后必须后退才能完成。
- 存档：每个区域入口满足安全条件后保存完整快照，恢复危险相位、绳索、奖励与机关状态。暂停冻结生产计时；两人都通过终点才结算，分别确认后继续。

主流程保留金币、合作奖品、共享护盾和共同失败。当前动物是野猪，不是牛。动画是关节摆动和躯干起伏，尚无逐脚地面 IK 或按速度精确调整步幅。
