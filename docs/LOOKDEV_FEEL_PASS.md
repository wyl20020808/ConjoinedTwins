# 画面质感第六刀：角色动态、命中与界面选中态

日期：2026-10-19。分支：`art/lookdev-feel`（从第五刀 `art/lookdev-landmarks@9d673e8` 继续）。

## 问题

前五刀把环境、光照、路面、界面和地标做出来了，但"动起来"仍偏僵：

- 角色横向移动时身体不转，看起来像贴着地面平移。
- 起跳落地没有重量，脚底和身体都像刚体。
- 开枪只有一块发光方块和一条弹道，没有照亮周围的光。
- 拾取物被拿走后直接消失，没有反馈。
- 第三章矿道空气是空的，缺少火星/余烬。
- 开始界面不显示当前选中的模式与难度。

## 改动

### 角色

- **横向转向**：按 `move_directions[i].x` 给角色根节点 ±0.42 弧度的偏航，10/s 平滑；前进/后退仍朝前，不破坏背对镜头的构图。
- **落地压缩**：从跳跃高度 >0.3 m 落到地面时，给角色模型 0.10 的横向膨胀、0.16 的纵向压缩，7/s 衰减；只改模型缩放，不改物理高度、碰撞、绳索挂点和镜头。
- 没有改跑步动画倍率。`journey_pursuit` 明确要求持枪前 Run 为 2.2 倍，本轮不动这个契约。

### 武器与命中

- 枪口增加 `OmniLight3D`（暖色、3.2 能量、3 m 范围、无阴影），与既有 0.065 秒枪口方块和弹道同时显隐；后坐力、弹道、换弹手势沿用原有实现。
- 拾取物被领走时，若距 01 小于 60 m，在原位爆一小簇火花；离开窗口的清理不触发。

### 环境

- 新增矿道余烬粒子：46 个细小暖色火星，在镜头前方 36×6×48 m 的盒体内缓慢上飘，只在第三章发射；森林落叶、村庄浮尘逻辑不变。

### 界面

- 开始界面的模式（单人＋搭档 / 远程双人）和难度（简单 / 普通 / 困难）增加选中态：暖金底、深色字、亮描边；只在开始界面刷新，不改变按钮布局。

## 未验收

- 没有真人试玩。转向角度、落地压缩幅度和枪口光强度都只能靠静帧与代码检查，实际手感需要跑图确认。
- 没有做脚部 IK 或步幅同步，跑步仍可能在高障碍/绳索拖拽时出现脚底打滑。
- 没有做命中顿帧、镜头震动或屏幕方向冲击；固定镜头不晃动的方向不变。
- 余烬在远处较淡，只有第三章近距离能看清。
- 只在 M4 / Metal / 720p 测过；网页、iOS 与 Windows 未运行。

## 既有测试的已知问题

`tests/speed_guidance_animation.gd` 在 macOS 上会因输出目录不存在而报 `store_string` 空引用；补建目录后仍会失败于"双人实际 8 米每秒"、"Jump 原速及物理相位"和"受击原速"等断言。该测试不在 `check_journey_performance.py` 的 26 项清单内，本轮没有修改它来掩盖失败；这些失败是否在第五刀之前就存在尚未单独对照。
