# 抱枪跑、射击姿势与双枪

日期：2026-10-21。分支：`feature/dual-weapon-carry`（从本地 `test@3bd21d8`）。对应试玩反馈：持枪跑步动画不对，应该抱着跑；射击动画可以改；双枪模式，一把拿着、一把背在背上。

## 抱枪跑与射击（`scripts/journey_combat_view.gd`）

原来：持枪层把右臂整链换成 `Idle_Gun_Pointing`，枪挂在右手腕上，于是跑步时一直单手前指。

现在改为“枪带手”：先按胸口骨骼位置（随跑步起伏）和身体朝向摆好枪，再用已有的双臂两段 IK（`reach_hand`）把右手放到握把、左手放到护木上。

- **抱枪**（不开火时）：右手握把在右腹前，枪身斜横胸前，枪口朝左上方。
- **瞄准**（按住开火，或开火后 0.45 秒内）：0.08 秒抬到胸口高度，枪身贴身居中，枪口指向锁定目标；没有目标时指向正前方。停火 0.35 秒后放回抱枪。
- **后坐**按枪种区分（时长 / 后移 / 上扬）：冲锋枪 0.065 秒 / 0.12 / 0.07，霰弹枪 0.16 秒 / 0.24 / 0.20，榴弹 0.2 秒 / 0.26 / 0.24，喷火器几乎不动。双手跟着枪一起后坐。
- **换弹**：仍是原来的抬枪、退弹匣动作，右手握枪、左手去拿弹匣。
- 步态层（`hero_locomotion.gd`）的持枪层只带胸口，双臂全部交给手部 IK（`journey_view.gd` 中 `gun_arms` 恒为 false）。
- 握持点按“右手握把在模型本地 (0, −0.10, 0.12)、左手护木在 (0, −0.06, −0.34)”。肩膀约在胸口锚点上方 0.5 米、左右各 0.28 米，手臂长约 0.87 米，姿势参数都在手臂够得着的范围内；测试中两种姿势双手误差均为 0。

## 双枪（`scripts/journey_combat.gd`）

- 战斗数据新增 `backups`（每人背上一把）和 `swap` 输入。旧存档与旧测试夹具没有这两个字段时，在固定步内按需补齐，联机两端一致。
- **拾取**：空手时拿在手上；手上有枪、背上空时，新枪背到背上；两处都满时不拾取。
- **换枪**：手上与背上互换；收起的枪中断换弹；换上的枪 0.3 秒（36 个固定步）内不能开火。背上没有枪时不动作。
- **丢枪**：丢下手上的枪后，背上的枪自动拿到手上。
- 移动速度规则不变：手上有枪就是 85%，背上的枪不额外减速。
- 存档快照包含背枪，恢复后一致。

## 输入与界面

- 键盘 **Q** 换枪；手柄 **LB** 换枪（本地双人时第二个手柄控制 02）；触屏右侧新增“换枪”小按钮。开始页、暂停页和手柄说明已加上换枪。
- 联机战斗命令由 3 个字段扩为 4 个（第 4 个为换枪）；旧版客户端发来的 3 字段命令仍然有效。
- 武器面板显示“背后：霰弹枪 · Q 换枪”（手柄、触屏显示对应按键）。
- 背上的枪斜挎在背后，枪口朝左肩上方，按类型显示对应模型。
