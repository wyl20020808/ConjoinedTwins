# 第二章 Boss 设计：烬翼魔龙

日期：2026-10-22。任务分支：`feature/dragon-boss`，从 `origin/test@f7e4cf8` 创建。本文是设计依据与实现记录；可见 GUI 试玩、真实手感与声音仍待用户验收，不得把设计目标当作已验收事实。

## 1. 定位与取舍

用户需求：第二关 Boss 参考第一关逻辑，是一条**会飞的恶龙**；出场时绕 Boss 场地飞一圈，落到地上咆哮，再喷出火焰。

沿用第一章（`docs/BOSS_CH1_DESIGN.md`）已被验证的框架，只替换“这只 Boss 是什么”：

| 沿用 | 改为魔龙特有 |
| --- | --- |
| 场地尺寸（章节末尾 1800 单位）、开战线、开战存档、失败从入口重打 | 入场：盘旋一圈 → 俯冲降落 → 咆哮 → 仰天喷火 |
| 护甲 25% / 硬直 100%、三阶段（65% / 30%）、每轮若干招后给破甲窗口 | 招式：半场吐息、甩尾冲击环、火雨与熔岩池、起飞横掠火线 |
| Boss 镜头、场地内可后退、射程 +25 米、定时补给 | 破甲：两人各站一块**绞盘踏板**（第二章合作门教过“双人踏板”），锁链把龙拽倒 |
| 入场期间锁操作、0.8 秒后按跳跃跳过 | 三阶段：两侧火墙代替荆棘 |

五条原则不变：看得懂再躲得开（每招有地面预警）、两人缺一不可（破甲要两人分站两块踏板）、节奏 = 压力 + 窗口、分阶段换招、固定镜头适配（龙只在道路远端或横穿镜头前方，不绕到镜头背后）。

## 2. 概念

- **名称**：烬翼魔龙，副标题“盘踞河谷尽头的焚天之翼”，位于第二章“水车河道”终点（河谷出口）。
- **外形**：黑色鳞甲、深红翼膜与腹部、胸口与喉部熔岩裂纹、橙色眼睛；半直立站姿，后腿站立、前肢短小，双翼张开呈 V 形，长尾拖地带尖刺。
- **体型**：模型放大 26 倍，身长约 25 米、站高约 16 米、翼展约 25 米；道路宽 32 米，落地时双翼几乎盖满路面。
- **弱点**：胸口熔岩核。平时被鳞甲覆盖（25% 伤害），被锁链拽倒时熔岩核暴露发光（满伤害）。
- **巢穴**：落点下一圈焦黑巨石、烧断的树干、骨骸与破蛋。开场运镜时巢穴冒烟，但龙不在巢里（不像第一章那样地下震动）。

## 3. 场地

逻辑坐标（20 单位 = 1 米），场地入口 `S = 章节长度 − 1800`：

- 开战线 `S + 300`；龙落点（髋部）`S + 1660`，瞄准点为胸口（落点前 130、离地约 9.6 米）；嘴在落点前 250。
- 龙存活时两人最多前进到 `S + 1380`；场地内可后退到 `S + 120`。
- 绞盘踏板：`S + 1080`，x = ±60（间距 120，小于绳长 146.6，两人可以同时站上）。绞盘立在路外两侧 `(±360, S + 1500)`。
- 入口：冲锋枪（左）与榴弹发射器（右），两箱弹药、两个医疗包。战斗中每 7 秒在两人附近掉一份补给（每第三次为医疗包，不落在踏板上），硬直结束在射击站位刷新弹药，换阶段刷新医疗包。
- 开战后入口燃起一道火线（只是画面）。

## 4. 战斗流程与数值

- 血量 **2400**，鳞甲 25% 伤害，锁链拽倒（硬直 7 秒）时 100%。
- 节奏：前摇倍率 1.0 / 0.88 / 0.75；每轮 2 / 3 / 3 招后必定“蓄焰”（破甲机会）；换阶段先怒吼 2.4 秒。

| 阶段 | 血量 | 招式池 |
| --- | --- | --- |
| 一 | 100%–65% | 烈焰吐息（单向）、甩尾震地（一道环）、火雨（5 颗） |
| 二 | 65%–30% | 加入起飞俯冲；吐息变为来回两道；甩尾两道环 |
| 三 | 30%–0 | 火雨 8 颗、熔岩池更久、横掠后横带留下熔岩；两侧火墙（贴边每秒扣 10） |

## 5. 技能

所有伤害走现有 `Combat.hit`：享受护盾、受击无敌，血量耗尽回存档点。

| 技能 | 前摇 / 预警 | 判定 | 伤害 | 躲避方式 |
| --- | --- | --- | --- | --- |
| **烈焰吐息** | 1.5 秒：后仰吸气，从嘴部铺开的扇形照亮将被烧的半场（先烧两人所在的那一半） | 火柱从正前方扫到一侧 80°，用时 1.4 秒，角宽 ±7°；火不能跳过 | 30 | 跑到另一半场地。二阶段起 0.8 秒后反向再扫另一半，第一道扫过后要立刻换边 |
| **甩尾震地** | 1.0 秒：拧身蓄力，脚下圆圈亮起 | 尾巴拍地，冲击环以 760 单位/秒向外扩散（半宽 26） | 30 | 环到脚下时跳起（高于 14）；二阶段起两道环间隔 0.7 秒 |
| **火雨** | 1.2 秒：仰头朝天喷火；落点圆圈跟着人走，喷火瞬间锁定（前两颗在两人脚下，其余在身边） | 1.1 秒后落地，半径 72 | 22 | 看到喷火后跑出圆圈；落点留下熔岩池 4 秒（三阶段 5.2 秒），踩上每秒 8 |
| **起飞俯冲**（二阶段起） | 1.2 秒起飞 → 绕到场地一侧，横带预警跟着两人走，2.6 秒锁定 | 低空从一侧横掠到另一侧（1.6 秒），嘴下一路喷火：在横带内（半宽 70）且离龙身横向 90 以内 | 30 | 锁定后前后离开横带；随后绕回落点降落 |
| **蓄焰 / 锁龙链**（破甲机会） | 1.0 秒：伏地、双翼裹身、胸口熔岩随呼吸鼓动，两块踏板亮起 | 两人各站一块踏板（落地）累计 2.6 秒 → 两侧绞盘射出锁链拽倒魔龙，硬直 7 秒；离开踏板时进度每秒回落 0.4 秒 | 吐向踏板的火球 18 | 每 3.2 秒朝一块踏板吐火球（飞行 1.1 秒、地面红圈），先让开再回来 |
| **炎爆**（蓄焰失败） | 13 秒内没拉满锁链；最后 1.6 秒警示 | 全场冲击环（820 单位/秒） | 32 | 跳起 |

“锁龙链”是第二章合作门“双人踏板 · 持续站稳”的战斗版，玩家在本章流程中已经学会；火球迫使两人轮流让开再回来，需要互相配合节奏。

## 6. 入场动画（约 15.3 秒）

| 时间 | 画面 | 声音与特效 |
| --- | --- | --- |
| 0–1.2 | 收起界面、黑边滑入，镜头从游戏视角抬向场地上空 | 远处一声龙吼 |
| 1.2–6.6 | 魔龙从远处高空飞入，以场地中段为圆心、半径 40 米、高约 22 米绕场地盘旋一整圈（经两人头顶），中段滑翔、其余振翅；镜头留在两人身后仰望追拍 | 每次振翅一声风压；掠过头顶时一阵翼风与龙吼 |
| 6.6–8.4 | 从远端俯冲降落，最后 0.6 秒转身面朝两人，后仰刹车、双翼前探猛扇；8.4 秒着地。镜头切到侧前方低机位 | 落地冲击：尘浪、碎石、冲击环、猛震、贴耳龙吼 |
| 9.1–11.5 | 正面低机位：吸气低头后挺胸仰头张大嘴，双翼高举颤抖；标题浮现 | 龙吼、两道冲击波、最强震动 |
| 11.5–14.1 | 侧前方仰拍：仰天喷出火柱 | 喷火声 |
| 14.1–15.3 | 镜头平滑落回 Boss 战镜头，黑边退出 | — |

入场期间两人不能移动、开火，不受伤害，魔龙不能被锁定；0.8 秒后任一人按跳跃跳到镜头交还段，用来跳过的跳跃不起跳。入场时间由模拟时间驱动，联机两端一致。

## 8. 特效（程序生成）

- 地面预警沿用 `boss_telegraph.gdshader`，新增扇形（shape 2）给吐息用；横带给俯冲用；圆圈给火雨、火球与冲击环蓄力用。
- 火焰：粒子面片用自定义着色器把圆斑撕成翻卷的火舌（滚动噪声、每个粒子相位不同），普通混合 + 高亮橙红色，叠在一起不会加成一片白。吐息火柱从嘴部沿模拟角度喷出，地面沿火柱翻起一条火带；横掠时嘴下一路喷火，横带上沿龙的轨迹起火；火雨前仰天喷出火柱。
- 冲击环：薄而亮的圆环，半径每帧按模拟更新；炎爆环更粗。
- 熔岩池：噪声着色器的熔岩圆盘，带补光，熄灭前淡出。
- 锁链：两侧绞盘射出 0.35 秒到达龙颈，铁环交错 90°、微微下垂，硬直结束收回。
- 胸口熔岩核：平时暗红补光随呼吸起伏，蓄焰时随锁链进度变亮，被拽倒时放大发白光。
- 三阶段两侧火墙与入口火线。

## 9. 实现结构

- `scripts/journey_dragon.gd`：魔龙模拟（纯数据、固定步、可存档、联机一致）。龙身位置 `body_pose()` 是模拟时间的纯函数（入场盘旋、俯冲降落、起飞横掠都由它给出），画面与瞄准点共用。
- `scripts/journey_boss.gd`：两章 Boss 的统一入口。`CHAPTERS` 加入第二章；`add / advance / hint / skip_intro` 按 `species=="dragon"` 分派；站位上限、护甲减伤、锁定规则两章共用。
- `scripts/journey_dragon_view.gd`：魔龙画面（只读模拟）。`journey_boss_view.gd` 的 `build / sync / intro_camera / paths` 按事件分派到这里（按需加载，避免循环预载），并复用其血条、黑边与泼土构件。
- 联动修改：`journey_combat.gd`（瞄准高度取事件的 `aim_height`，龙飞起时随之升高）、`journey_view.gd`（预载资源按 Boss 取）、`journey_opening.gd`（魔龙巢穴只冒烟、不震动）、`sfx.gd`（登记两条新音效）、`chapter_catalog.gd`（第二章简介与提示）、`boss_telegraph.gdshader`（扇形）。
