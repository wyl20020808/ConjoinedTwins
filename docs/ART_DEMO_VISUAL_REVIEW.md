# 归航 Demo 美术自查

范围：执行者实际读取最终生产截图进行自查，不是决策者验收或用户确认。截图由 Godot 4.7.1 的真实主场景生成，生产输入和 AI 驱动跑完道路；不是素材页截图、拼贴或独立概念渲染。

## 取得方式与策略边界

实时策略外部路径无法读取，按 AGENTS.md 默认使用 work。`build-tools/capture_hidden.py` 从创建时就建立任务独占、无 WS_VISIBLE 的父窗口，通过 `--wid` 将 Godot 渲染窗口嵌入；父窗口从未显示。脚本没有 ShowWindow、SetFocus、SetForegroundWindow、用户输入、剪贴板或浏览器操作；只处理自己窗口消息，任务退出后销毁自己窗口并回收子进程。Godot 用 Dummy 音频，CREATE_NO_WINDOW 启动控制台子进程。本机 NVIDIA OpenGL Compatibility 渲染已实际取得像素。

该方式不是 headless Dummy 渲染，而是用户授权的从创建起隐藏的非交互渲染。可见 GUI 与真人输入仍为 deferred_by_work_mode / 待用户试玩。日志 `tests/capture.log`，场景状态 `docs/screenshots/capture.json`，最终文件哈希 `docs/ART_DEMO_EVIDENCE.json`。

## 实际发现与修复

1. 初次运行工业模型按高度缩放导致低矮建筑过宽，遮住道路和角色。限制工业资产宽度不超过 8 米后重新运行截图，道路与双方轮廓恢复清楚。
2. 初次导入未复制 GLB 引用的共享 colormap，建筑呈白色。补齐原贴图依赖，并在运行材质明确绑定共享调色板；同步降低太阳和环境亮度、略调暗建筑，使路障和角色识别灯保持可读。
3. 区段门架经过角色时遮住画面。保持远处可见，距角色约 12 米时将门架退场；所有镜头参数保持不变，无旋转、摇晃或变焦。
4. 加宽工业地台，避免近处建筑浮在空背景上；增大机甲显示比例，保持碰撞逻辑原尺度不变。
5. 替换细圆柱连线为清晰发光细梁，消除显示不明显问题；压缩进度条为 4 像素，避免占用 HUD 下方画面。
