# 画面质感第一刀：镜头、遮挡与空气感

日期：2026-10-19。分支：`art/lookdev-composition`（起点 `test@392fccc`）。

## 问题

固定种子实机截图（1280×720、Forward+、Metal，六处观察点）显示，"粗制滥造"主要来自整体完成度而不是单个模型：

- 角色只占画面高度约八分之一，画面底部 35%–40% 是空路面，上方三分之一是发灰的天空。
- 刚通过的水晶门（`arch_teal` / `arch_amber`）停在镜头前下方，连同大号 01/02 标签挡住约 20% 画面。
- 全图一层粉紫晚雾，物体亮度趋同；树、房屋、路面、怪物没有明确的主光、补光和阴影层次。
- 路缘草皮条每 4 米重复、环形落叶堆每 8 米等距复制，近景像贴图地毯。

本轮先处理不依赖新资产、收益最大的四项，作为后续材质、光照、UI 步骤的基线。

## 改动

### 镜头

`scripts/journey_view.gd`：相机 `(0, 11.5, 22)` → `(0, 9.6, 18)`，FOV 62° → 57°，看向点 1.2 米 → 1.4 米。朝向仍固定，不旋转、不晃动；角色在画面中约增大三成，底部空路面减少。

### 通过后的水晶门淡出

`scripts/journey_view.gd`：颜色门落后角色 2 米开始淡出、11 米完全隐藏，整座拱门与 01/02 标签一起渐隐。使用 `GeometryInstance3D.transparency` 与标签透明度，不改材质、不改碰撞与判定。此前门体在镜头下缘长期停留，既挡前路又与角色头顶标签重复。

### 雾、调色与抗锯齿

- `scripts/journey_view.gd`：深度雾密度 `0.0032/0.0065` → `0.0021/0.0042`（非林地/林地）。
- `scripts/journey_atmosphere.gd`：体积雾 `0.0012/0.0035` → `0.0008/0.0022`；空气透视 0.75 → 0.6；AgX 曝光 1.05 → 1.0；对比度 1.12 → 1.18；饱和度 1.12 → 1.16；SSAO 强度 2.2 → 2.6。
- `project.godot`：开启 debanding。
- TAA 实测代价过高，未启用，见下表。

### 落叶堆重复度

`scripts/journey_landscape.gd`：用坐标散列打散环形落叶堆的朝向（±0.35 弧度）、大小（0.78–1.0）、横向偏移与约 22% 的删除率。安全切片检查框放大到 4.8 米，保证旋转、缩放和偏移后的实际网格不会桥接缺口。

## 未验收

- 没有真人试玩。镜头更近后的晕动感、角色占屏比例、机关提前量与救援特写是否仍然舒服，需要用户实机确认。
- 只在 M4 / Metal / 720p 测过；Windows、网页、iOS 未运行。
- 地面材质、天空、房屋与树木重复度、UI、角色动画仍属后续步骤，本轮未改。
- 本轮未使用 Blender、Tripo 或互联网新资产；后续材质与地标步骤再决定是否生产。
