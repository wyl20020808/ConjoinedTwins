# 连续旅程存档点加密：失败后回到离死亡点更近的位置

日期：2026-10-20。分支：`fix/closer-checkpoints`（从 `test@92f6661` 新建，独立 worktree `/Users/apple/ConjoinedTwins-checkpoints`）。

## 原规则与问题

`scripts/journey_run.gd` 的 `update_checkpoint()` 每个区域只存一次：进入区域 3 米后，两人贴地、绳未挂障碍、800 单位内没有进行中的攻击、脚下 80 单位内没有任何机关时，保存完整对局快照。第一章每区 6400 单位（320 米，约 20 秒步行），第二、三章每区 5000 单位。

旅程机关和敌群很密（主机关约每 12 米一拍，敌群每 900 单位一群），玩家多在区域中后段失败，回退距离常接近整个区域。测试驾驶实测：第一章死于 2764，回到 62（回退 2702）；第二章死于 5412，回到 62（回退 5350）。第三章入口规则直到 1292 才满足，此前失败只能整关重开。

父类 `road_run.gd` 的 `checkpoint_safe()` 按“恢复后不按键会沿原路直行 1 秒”设计，适合自动推进道路；旅程无输入时角色原地不动，套用它在密集路段几乎从不放行。

## 新规则

区域入口存档保持原规则不变，另加两条：

1. **区域内补充存档**：距上一存档至少 800 单位（40 米，约 2.5 秒步行）后，每 0.1 秒判定一次，满足以下全部条件时顺延保存：
   - 两人贴地有支撑，绳未挂障碍、未受阻、未解绕；
   - 两人血量都不低于 50（恢复后至少能再挨一次任何攻击）；
   - 距未开合作机关 800 单位以上、已开机关 300 单位以上；不在窄路（中央独木道、崖边单行、镂空桥）范围内；
   - 不在任何敌人出生点 80 单位内（敌人已倒下也一样）；存活敌人在 360 单位外（近战距离之外），且附近没有正在预警或攻击的敌人；
   - 不在倒树、推车、投掷、摆臂等事件的作用区内，已触发的事件再多留 240 单位；
   - 所有机关按当前采样包络（周期机关取完整运动包络、缺口按真实形状）不进入两人及绳索外扩 48 单位的留白框；同一路线带（左右 160 单位）内没有前后逼近的移动危险，按相对速度 2 秒内也不会到达。
2. **区域入口兜底**：进入新区域后若原入口规则迟迟不满足，按补充规则保存该区域第一个存档。

判定只读同步状态、在固定步内执行，联机两端在同一步得出相同结果；存档内容、恢复流程、1 秒无敌和输入屏蔽全部沿用原快照机制，没有新增位置修正或瞬移。失败面板文案改为“回到最近的安全存档点”。

单次快照约 0.75–0.85 ms，单次补充判定 0.1–0.4 ms（M4 headless），只在距上一存档超过间距后每 0.1 秒执行一次。

## 验证

新增 `tests/journey_checkpoint_spacing.gd`：

- 单项拒绝：未开机关前、近身敌人、已倒下敌人的出生点、窄路、低血量时都不补充存档。
- 实战三章：测试驾驶（`tests/fixtures/journey_route.gd` + 搭档 AI）只给离散按键，失败后和玩家一样从存档继续，同一存档连续失败 3 次时结束本章。
- 战斗清空三章：模拟打倒每群敌人后前进，每 40 米再强制失败一次，统计回退距离。
- 每个存档都复核：快照中两人贴地有支撑、不压静止机关；补充存档间距不低于下限、血量足够、不在机关/窄路/出生点。每次恢复后局面与保存时一致，在恢复瞬间重新复核补充或入口规则，并确认恢复保护生效、重复恢复得到相同局面。

结果（`checks=5206 failures=0`）：

| 轮次 | 死亡点 → 恢复点（原规则恢复点） |
| --- | --- |
| 实战第一章 | 2764 → 1317（原 62），回退 1447 / 2702 |
| 实战第二章 | 5412 → 4896（原 62），回退 516 / 5350 |
| 实战第三章 | 2518 → 83（原规则无存档，整关重开） |
| 合计 24 次失败 | 平均回退 1104，原规则 2936，下降约 62% |

第三章 400–2500 之间连续是镂空窄路、水车摆臂、敌群出生点和滚球，测试驾驶不打怪也走不出这段，期间没有满足条件的安全时刻；真人清掉敌群后的实际间距待试玩确认。

既有测试：`tests/journey_headless.gd`（206 项失败）和 `tests/checkpoint.gd`（线程调用崩溃）在未改动的 `test@92f6661` 上结果完全相同，属既有问题，不在性能检查清单内。`python3 build-tools/check_journey_performance.py --godot /Applications/Godot.app/Contents/MacOS/Godot` 26 组全部通过，报告在 `/Users/apple/ConjoinedTwins-task-temp/closer-checkpoints-perf-20261020/summary.json`（headless 功能、CPU 与资源生命周期，不含 GPU 帧率与真人输入）。
