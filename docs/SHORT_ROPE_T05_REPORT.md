# t05：公平段落生成与生产输入回放

本轮根据决策者初轮返工意见完成键盘路线修正及重新自测，等待新一轮决策者验收。初轮比例方向证书不能作为键盘可执行路线通过证据。没有提交、初始化 Git、合并、推送、发布或更新 Mac 包；工作目录没有 Git 仓库。没有启动可见窗口、操作键盘鼠标或用户浏览器。

## 键盘路线返工

初轮决策审查发现前后段落使用了任意比例方向。原交付报告、源码及结果快照保存在 `build-tools/short-rope-t05/keyboard-rework/`；决策者证据保留在 `decision-review/`。这些旧证书仅为历史成果，不代表当前键盘路线验收。

控制器现在输出停止、四轴向和四对角的原始按键轴值，禁止模拟摇杆。半个固定步位移作为停止死区；段尾中央残差容限明确为一个轴向固定步加 0.01 单位，即 1.093333 地面单位（约 5.47 厘米）。实测段落最大残差为 0.507161 单位（约 2.54 厘米）。没有放宽绳长、碰撞、奖励或预警判据，也没有位置吸附、瞬移或物理修改。

记录的六列依次为 01 横轴、01 前后轴、02 横轴、02 前后轴、空格按下状态、回车按下状态。01 横轴 -1/1 等价于 A/D，前后轴 -1/1 等价于 S/W；02 横轴 -1/1 等价于左/右，前后轴 -1/1 等价于下/上。0 表示该轴无净输入；组合两轴交给生产 step 归一化。

返工初轮普通难度出现纵向修正触发前进键，使首次 TTC 降到 1.603585 秒；该失败观察已保存。普通段现在在危险接近时只共同横移，在危险通过后的出口区修正纵向残差；前后合作段继续使用真实方向键。接触专项改为 01 纯后退、随后右后斜移，02 在解除接触后同侧移动。

段落验证、整关记录和复放、最终源码复放均加入独立输入合法性断言。Python 另对保存的证书独立审计 812,208 个双方方向样本，非法输入为 0，实际涵盖全部九种键盘原始方向；证据见 `tests/short-rope-t05-keyboard-audit.json`。

整关检查按 easy / normal / hard 分批保存，每个种子的记录及复放后落盘 checkpoint；未完成批次标记 completed=false、passed=false。只有三个 completed=true 且 passed=true 的批次可以合并为新的整关结果。本轮三个批次均退出码 0，27 关及其对应 27 关复放全部通过，不借用旧 272 项结果。

## 实际改动

- `scripts/road_templates.gd` 移除旧 11 米绳长及固定右侧包络证书，改为共同左绕、右绕、双人跳跃、同侧绕柱、同侧避球、迎面低空跳跃、前后配合、双威胁八种段落。种子控制左右变体和无解候选注入；前两关逐步教学，第三关加入双威胁。
- 每段提供现有键盘原始轴值（每轴只能为 -1、0、1）及空格/回车按下序列；对角归一化仍由生产 step 执行，实际运行 `road_run.gd` 的固定步、连续碰撞、绳索、动态威胁和奖励逻辑。验证实例只关闭递归生成，保持生产流式回收、速度、重定位和关卡配置。没有测试专用运动或碰撞模型，没有自动接管生产玩家。
- 验证检查两人短绳约束、全部奖励可达、没有护盾抵伤、TTC 预警足够、双人落地及中央出口。缓存键包含完整布局、关号和难度；宽墙候选经真实输入失败后，回退到已通过同一生产验证的安全段。拒绝记录保存原因、失败状态、候选摘要和安全证书标识。
- `scripts/road_run.gd` 的生产流式入口改为使用新生成器，统一安装危险与奖励，保存并有界回收段落路线。提前加载的迎面物保持可见，到段落入口开始运动，避免加载时间改变组合轨迹；运动起点随坐标重定位平移。重试重置稳定障碍编号，保证同种子、配置和输入复现。
- 修正提前加载窗口多算一段导致奖励超限的问题，并增加简单难度迎面物初始距离，保证预警时间。复用现有危险节点池、63 个道路槽及 24 个奖励槽；没有修改历史白盒物理常量、已有资产或许可证。
- README 更新当前验证入口、历史固定走廊测试的适用边界。新增四个 t05 headless 验证入口。

## 启动与复测

用户启动：双击项目根目录 `启动归航Demo.cmd`，或用 Godot 运行 `scenes/road_demo.tscn`。生产入口仍为本地双人、自动推进和固定道路纵深镜头。

```powershell
& "D:/Tools/Godot/4.7.1/Godot_v4.7.1-stable_win64_console.exe" --headless --path "D:/ConjoinedTwins" --script res://tests/short_rope_t05_headless.gd --log-file "D:/ConjoinedTwins/tests/short-rope-t05-headless.log"
```

将上述 script 分别换成 `short_rope_t05_catalog.gd`、`short_rope_t05_state.gd` 或 `short_rope_t05_final_replay.gd` 即可运行专项。最终源码复放需要先存在完整整关结果。
