# 道路纵深美术 Demo：当前开发方向

日期：2026-10-12。来源：用户看过白盒后的新要求及镜头选择。本方向在镜头、场景呈现和本轮 Demo 范围上优先于初期方案；其余连接与离线 AI 合作原则继续保留。

> 当前生产方向（短绳三关）：仅本地双人，01 WASD / 空格跳跃，02 方向键 / 回车跳跃。固定道路纵深镜头、自动推进，双方前后范围各 ±5 米，生产绳长 7.33 米，独立快跳最高 1.8 米。圆柱及滚球使用连续接触绕障路径；迎面飞行物、共享金币/奖品/护盾、共同终点和双方确认下一关已接入，三关基础目标各约 100 秒。无 AI、单人入口、趴下或爬行。保留宽道路、骨骼动画和已有资产许可。下文是早期画面方向及 450 米 Demo 的历史范围，不再限制当前玩法；当前契约及未验收边界见 [短绳当前设计](SHORT_ROPE_CURRENT_DESIGN.md) 和 [t06 报告](SHORT_ROPE_T06_REPORT.md)。

## 用户明确选择

画面沿道路向远方推进，参考《地铁跑酷》《神庙逃亡》的纵深构图，不采用英雄联盟式自由斜俯视。表现偏 2D / 2.5D，以减轻自由 3D 镜头带来的不适。所有游戏画面应统一调整，不只替换某个角色或加一张背景。

本轮重点是现代游戏观感：两个真实角色资产、完整道路环境、障碍与机关美术、光影、纵深、界面和反馈。玩法保持简单，不开发复杂战斗、装备、技能树、网络或角色动画系统。

## 镜头与体验

- 道路收向远处的消失点，近大远小；角色位于画面近处，道路、障碍和远景有清楚的层次。
- 镜头朝向与俯角固定，不允许玩家旋转、自由观察；无镜头震动、突然变焦、视角急转或强运动模糊。
- 默认解释为自动向前推进的小段跑酷：人类控制左右位置，可用简单前后调节或暂停/减速辅助测试；AI 队友协同避障，始终受连线距离限制。
- 可采用 2D 透视投影、预渲染资产或固定镜头的风格化 3D 底层。技术选择服务于偏 2D、稳定镜头和道路纵深的结果，不要求玩家使用 3D 控制。
- 区分地面逻辑坐标与屏幕坐标。连接限制、碰撞和 AI 使用同一地面尺度；点击指令若保留，必须反投影到地面，不能继续把屏幕像素直接当世界坐标。

## 美术基调

默认采用清晰、风格化的未来城市 / 能量设施通道。道路与建筑材料、配色、角色比例、阴影方向、光源和 UI 统一。可有青蓝与暖橙作为两角色的识别色，深色地面配适量灯带与装饰，避免刺眼闪烁和过密霓虹。

不把纯几何白盒、像素涂色或仅换配色当作最终美术完成。两名角色应有可辨认的头部、身体、装备/结构和不同轮廓；允许静态姿态与朝向变化，不要求本轮实现走跑动画。移动表现应匹配静态角色，例如机器人滑行/悬浮，不使用明显 T-pose。

道路需有连续纹理或模块、边界/栏杆、路面标识、侧边建筑或设施、远景和环境装饰。障碍应由可辨认的模型/贴图呈现，例如路障、货箱、闸门或能量屏障；检查点、出口和连接线也要有与场景一致的视觉表达。

## 小 Demo 范围

一段约 60–90 秒的精心布置道路即可，可分为安全起步、简单避障、合作终点三个连续区段。该时长是设计目标，实际速度以试玩校准。所有可进入的游戏视图使用新表现；旧白盒若保留，只作为明确标识的历史/调试入口，不混入新 Demo 主体验。

必须保留：

1. 人类玩家 + 离线确定性 AI 队友，两个不同角色。
2. 自动推进、简单横向移动、地面碰撞与连线长度限制。
3. 少量易读障碍或危险，两人合作通过；死亡/失败、重试和到达终点闭环。
4. 暂停、重开、基本操作说明；可保留本地双人测试模式。
5. 有实际设计的开始/暂停/结束 UI，控制与当前跑酷逻辑一致。

不要求完整新游戏、不继续堆积旧三关的复杂机关；无需角色动画、敌人、战斗和商店系统。可以修改关卡布局以适配新镜头，不通过关闭碰撞或连线限制换取视觉结果。

- 必须检查实际新 Demo 的画面：两个角色、道路纵深、资产比例、阴影、遮挡、HUD、危险可读性；保存运行画面的截图供审查，不能用素材页图片或拼贴概念图冒充运行截图。
