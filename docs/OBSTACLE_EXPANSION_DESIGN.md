# 道路障碍扩展设计与 t01、t02 参数

本轮 Run：`6377e8b8-0915-462e-8cd5-50e0de0ad7d6`。本文区分本轮基础实施与后续任务，不把设计要求当作验收事实。生产入口继续本地双人、固定镜头、四向移动和独立跳跃，不提供趴下、爬行、主玩法 AI 或自动接管。

## 实施顺序

1. t01：保留连续碰撞和绕球硬约束，石球、铁球主动迎面提速；新增独立火箭；提高道路基础推进速度，重算迎面起点、预加载及出口时间。
2. t02：旋转扫杆、道路缺口。先局部低扫杆和短缺口的稳定同侧绕行，再教授独立跳跃与前后错峰双跳；长缺口明确只能绕行。
3. t03：俯冲无人机、横穿叉车、重型压机。每种先单独教学。
4. t04：摆动巨锤、塌陷地板、错峰蒸汽喷口。每种先单独教学。
5. t05：教学后的可解组合、障碍增密与规律金币。跨段的实际双人状态验证及整关回放通过后才允许组合。

当前已实施 t01–t05，最终检查与分层验收见各任务报告。新机制首次教学沿用所在关卡的固定基础推进速度，不同时添加速度爬升或段内组合。难度和关号决定速度；没有段内加速。保留历史配置字段不代表它们正在生产中生效。

## t02 生产参数与支撑契约

`road_surfaces.gd` 提供扫杆与缺口的公共几何。扫杆全长 2.4 米、杆体半径 0.1 米、危险顶部 0.6 米，支座半径 0.25 米、高 2 米，角速度 0.9 弧度/秒。杆体、支座和旋转期间扫过的区域分别检测；绳索按每段实际高度判碰撞。模型及预警读取相同几何，支座不能通过跳跃或护盾穿越。

短缺口沿道路长 1.4 米；长缺口长 12.6 米、宽 8 米。当前最快基础推进为 10.44 米/秒，手动前进为 8 米/秒，腾空 0.6 秒；即使忽略脚底半径，最大前向跳程上界也仅为 `(10.44 + 8) × 0.6 = 11.064` 米。长缺口超过该上界，并在同侧保留宽 8.3 米的连续道路。短缺口起跳以各玩家实际前向位置计算，提前 0.3 秒起跳；完整脚底圆盘在起落时均须有支撑，不能只检查角色中心。护盾、无敌和绳索均不提供支撑。

每关在既有教学后依次进入 `sweep_bypass`、`gap_bypass`、`sweep_single`、`gap_single`、`sweep_double`、`gap_double`、`gap_long`。双跳先建立前后错位，再由两人的真实位置分别起跳。长缺口奖励和回中位置移到坑后安全道路。专项检验九组关速、左右镜像、角色交换、紧绳、暂停、重试、池复用和重定位；生产流程证据与可见画面验收分别记录。

## 预警、预加载与通行余量

- 双人共同换边时间：分别计算两人到危险同一侧安全边界的距离，取双方最大时间，再取合法左、右方案中较短者。边界计入角色半径和 0.1 米间隙。共同横移是合法四向输入，不要求对角输入或按比例方向。
- 预警提前量取难度配置 2.4/2.0/1.8 秒与共同换边时间加 0.35 秒反应余量的较大值。相对速度来自当前双方实际前向输入与危险速度。锁定后方向不追踪玩家。
- 所有生产迎面物的起点按 `(关速 - 危险纵向速度) × (配置提前量 + 0.05 秒) + 前方调节上限 + 角色半径` 重算。这样最前角色在入口也保留配置提前量；原低空跳跃机制保留。
- 预加载距离本次从 144 提高到 168 米（初版为 120 米）；预加载危险提前可见并允许标示，仍在所在段入口开始运动。最快关速加全速手动前进与火箭的最大相对速度为 36.44 米/秒，2.4 秒覆盖 87.456 米；另计 5 米前后范围、3.2 米火箭长度和一个 42 米流式段，总计 137.656 米，小于 168 米。此预算覆盖本轮中央教学危险，不是任意全幅障碍的可解证明；后续更宽或封路布局必须重算共同换边、绳段与窗口。
- 提速后，路线证明器按实际横移速度预留返回中央的时间：返回起点不晚于 `段长 - 关速 × (侧移距离/手动速度 + 0.10 秒)`。保留原单步出口误差，不能扩大容限或吸附角色。
- 教学段本次从 36 米调整为 42 米（初版为 30 米），预加载仍为四个段长度。前后合作退出需先恢复横向位置再修正前后残差，因此不能只保留旧段的出口距离；迎面危险真实包络完全经过双方后才返回中央，避免固定 450 单位回中切入尚未通过的球体。保持奖励数量与原教学顺序，不同时增密；后续增密由 t05 单独验证。
- 暂停冻结动态运动、预警与接触。重试清空触发、偏移、锁定、运动里程与受阻计时；节点按类型复用。重定位同时移动角色、静态起点、绳路径及段入口；动态偏移不重复移动。

## t04 生产参数与共同窗口

巨锤柄长 9 米，水平摆角 ±1.1 弧度，锤头与柄分开检测；支架持续为实体。周期为预警 2.4 秒、下降 0.45 秒、摆动 4 秒、上升 0.7 秒、抬起通行 4.2 秒。旋转柄采用实际朝向盒与分段保守扫掠，实际绳高同步插值。地面提示和流式回收均覆盖完整摆动包络；锤头暂时离路不能使柄消失。独立教学沿锤架相反一侧通过，包络退出后在段内 650 单位开始回中。

塌陷板宽 8 米、纵深 3 米。第一次地面脚底实际接触启动裂纹，0.75 秒后进入退出宽限；总宽限为 `(板长 + 两倍角色半径 + 146.6 最大地面绳长) / 当前固定关速 + 0.35 秒`。获准入口是无绳索挂点和受阻、前后差不超过最大地面绳长的正常前进状态；驻足、倒退不会延长计时。单跳、双跳不把绳索变成支撑，塌后复用真实道路缺口规则。重试和新实例恢复完整板面。

蒸汽周期为预警 2.4 秒、升压 0.4 秒、喷射 0.8 秒、消退 0.3 秒、安全 2.1 秒；两个喷口相位差 3 秒，喷流最高 5 米。喷射和收缩中的消退体积检测角色及实际每段绳高；边界按阶段切分，消退完成立即不伤害。两个喷口均位于中央局部，保留同侧连续旁路，不要求趴下或荡绳。

第一关先保留滚球，再安排巨锤、塌陷板、蒸汽及 t03、t02 独立教学，然后优先保留高柱、低空物等已有类型，再放原重复练习，确保 100 秒关长内新教学实际出现。其他关保留两种球和火箭基础教学后进入新增教学，高柱、低空物、身体高度物优先于重复左右练习。各段仍由生产固定步、合法键盘轴和奖励/出口约束验证；本轮不添加组合或增密。检查与未验收边界见 [t04 报告](OBSTACLE_EXPANSION_T04_REPORT.md)。

## 障碍契约

| 障碍 | 教学与合法应对 | 必须检验的真实规则 |
| --- | --- | --- |
| 旋转扫杆 | 先局部扫杆同侧绕行，再同步跳跃 | 杆体、支架和整个旋转扫掠分别碰撞；低杆高度允许当前跳跃；提示和危险范围同源 |
| 道路缺口 | 先短缺口同侧绕行，再同步跳跃；长缺口绕行 | 地面真实失去支撑；长度按实际关速、0.6 秒腾空和安全起落位置求解，不能只用纸面跳距；任一人失支撑共同失败 |
| 俯冲无人机 | 提前显示起点、方向、落点和高度；同侧避让 | 发射后固定斜向轨迹，不追踪；角色连续高度碰撞和实际绳段检测 |
| 横穿叉车 | 先同侧通路，再前后错位通过 | 车体、货叉、载货箱为真实实体；绳段命中共同失败，护盾不穿货箱，不通过扩展道路避险 |
| 重型压机 | 预警、下压、停留、抬升；先稳定绕行 | 窗口覆盖后方角色和实际绳段完全退出；无安全等待区或共同窗口时拒绝全幅布局 |
| 摆动巨锤 | 明确摆向和通行窗口 | 锤头、支架、连接结构及整个摆动扫掠，不能只采端点 |
| 塌陷地板 | 首次踩踏裂纹预警，双人退出余量 | 使用真实支撑状态；先后踩踏不重复延长计时；重试和复用恢复完整地板 |
| 错峰蒸汽喷口 | 明确预警、喷发、冷却，稳定同侧通路 | 错峰必须形成双人共同窗口，非两人各自安全但绳段被切；真实高度与激活边界连续检测 |

## 组合禁区与跨段验证

- 禁止缺口内叠低扫杆、危险落点、塌陷板或无安全着地位置。
- 禁止叉车与其他危险封死同侧通路，或压机/巨锤/蒸汽各自有窗口但没有两人和连线共同窗口。
- 禁止塌陷板叠必须驻足的奖励或等待型机关；奖励不能诱导角色进入必死路径。
- 高速滚球、火箭与新障碍先按时间分离，不能压缩共同预警、退出和返回中央的余量。
- 验证必须使用同一生产速度、种子、真实键盘轴值、实际绳段高度、支撑和碰撞；跨段携带前后差、跳跃、触发、接触与奖励状态。
- 无法证明可解则回退经过同一状态验证的安全段；安全段也失败则停止生成并留证。禁止瞬移、免伤通路、放宽绳长或修改可信检查来掩盖失败。

## 恢复与验证边界

### t05 当前生产编排与证书

第一关完整保留八类独立教学和扫杆/缺口的七种进阶。第二、三关在八类复习后优先安排旧身体高度物、错峰与双威胁，避免 100 秒内只见新教学而吞掉旧玩法。白名单仅包含 `pillar_press`（高柱与侧边压机）和 `low_steam`（低空物与侧边蒸汽），各自有明确安全同侧走廊。其他混合新障碍组合、滚球或火箭与新障碍同段均拒绝；高速滚球和火箭仍独立串联。

段长 840 单位，首段从 500 单位开始，申请窗口为 840 单位；这取代上文历史的 3360 单位批量预加载。生产场景采用后台证明：主线程锁定候选、随机状态、完整真实提交入口和源码哈希；工作线程独占离树克隆，逐固定步预测至出口。安装前检查 epoch、入口与布局绑定、实际源码字节哈希、合法交接域和截止距离。证明针对提交入口的存在路线，交接时的实际状态另行记录及检查，不把预测状态冒充安装时状态。重试、结算、退出均合作取消并 join；失败停止生成并保存原因。

候选与安全回退必须使用同一入口。第一轮教学失败直接停止，不能回退为安全空段而让教学消失。证书绑定最终速度、固定步、布局、支撑规则及相位，缓存上限 32。源码校验使用实际文件字节 SHA256，不能仅凭秒级修改时间复用旧证书。

金币每约 90 单位交替沿安全地面轨迹排列，跳跃期间不在危险起落点布置诱导币。在线证明生成金币只改变计分，不改变运动；最后静态布局仍须在三关实录和逐步复放中全部领取。奖励槽固定扩为 64，危险上限 32，实例 ID 独立去重；跨段金币最大间距使用 240 单位固定上限验收。
