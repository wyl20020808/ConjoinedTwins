# 第一章 BOSS 战斗与死亡演出

任务分支：`feature/boss-combat-finale`。开发起点为本地 `test` 的 `f64897f`；开工时该分支领先远端 4 个提交。原工作区的启动器改动保留。

战斗动作放大相对静止骨架的旋转，保持根部位置及原有伤害判定、技能前摇。每种技能分别在蓄力和释放时发声，双臂横扫有第二次挥动声，破甲有受创吼声。

声音包含三条蓄力低吼、三条出招怒吼、两条受创嘶吼、一条死亡长嚎和一条断裂声。它们由 `build-tools/boss/make_combat_voice.py` 独立合成，包络、音高轨迹、噪声及木质共鸣各不相同，同组音频不连续重复。保留原入场声音与用户的音量设置。

死亡演出长 10.5 秒：镜头推近，巨像仰天长嚎；2.2 秒起本体沿裂缝发光并逐渐撑开；4 秒爆裂，原身体的 28 个块体旋转飞散，随后消隐；7.5 秒显示“恭喜通关”和第一章完成文字，最后镜头回到玩家。模拟期间锁定移动和伤害，暂停冻结演出，重试清除一次性播放标记。结束后继续走到章节终点，沿用原结算流程。

碎块由 `build-tools/boss/fracture_colossus.py` 在 Blender 后台从原 `root_colossus.glb` 的真实蒙皮网格生成。固定咆哮末姿，按 Voronoi 平面切割、封闭切面；外表保留原 UV 和材质，新增深色发光木质断面。导出的 GLB 约 2.9 MB，切割种子存于旁边 JSON；原始模型未改动。碎块预载并复用，死亡时不执行切割计算。裂缝着色使用同一组切割种子。素材权利沿用原模型来源；新增声音为程序合成。

试玩入口：根目录 `play-boss-combat.cmd`。自动演出预览：`preview-boss-finale.cmd`，复用生产入场和约 12 秒战斗后，通过正常伤害接口击败 BOSS；自动击杀只存在于该预览工具。
