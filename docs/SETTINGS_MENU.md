# B4 设置页、手柄与章节进度条

日期：2026-10-20。分支：`feature/settings-menu`（从本地 `test@4d86f1f` 新建，独立 worktree）。对应 [质感升级方案](GAME_QUALITY_UPGRADE_PLAN.md) 的 B4 第 1–4 项；第 5 项（色弱模式、关键音效文字提示）和按键重映射不在本次范围内。

## 原来

开始页和暂停页没有设置；音量只能靠系统，画质固定为“桌面最高 / 网页缩放到 960×540”。暂停菜单里只有一个“画面冲击与震动”开关。输入只读键盘、鼠标和触屏，手柄只用于震动。HUD 不显示本章进度和区域。

## 改动

### 设置页

- 入口：开始页与暂停页的“设置 · 音量、画质、手柄”按钮。打开后主面板收起；“返回”、Esc 或手柄 B 关闭设置页，不会顺带恢复游戏。联机时队友恢复游戏（状态离开开始页 / 暂停页）时，设置页自动收起并保存。设置只改本机表现，不发送联机命令。
- **音量**：总音量、音乐、音效、环境四个滑条（0–100%，步长 5%），按线性写到 Master / Music / SFX / Ambience 总线；UI 总线跟随“音效”。环境声在 `pump_ambience` 中写入 `战斗压低 × 用户音量`，两者相乘、互不覆盖。
- **画质预设**（`scripts/journey_settings.gd`）：

  | 平台 | 低 | 中 | 高 |
  | --- | --- | --- | --- |
  | 桌面 Forward+ | 无阴影、无体积雾、无 SSAO，内部渲染高度 540，无 MSAA | 有阴影与 SSAO，无体积雾，渲染高度 680 | 原有画质：阴影、体积雾、SSAO，渲染高度 800 |
  | 网页 Compatibility | 3D 最多 768×432 | 原有 960×540 | 最多 1280×720 |
  | 移动原生 | 渲染缩放 0.6 | 原有 0.75 | 0.9 |

  桌面默认“高”、网页与移动默认“中”，都等于原有画质。网页没有体积雾和 SSAO，动态阴影保持关闭，只调分辨率。窗口高度不超过目标渲染高度时保持原生分辨率；更高时沿用 MetalFX / FSR2 时间性超分。
- **帧率上限**：桌面 30 / 60 / 120 / 不限（默认不限，仍受垂直同步约束）；网页 30 / 60（默认 60，与原来一致）。桌面默认“不限”时启动不改 `Engine.max_fps`，保留启动入口或测试预设的上限；只有玩家选了上限，或在设置页切换时才写入。
- **伤害数字**：关闭后敌人头顶不再显示“-10”，“击败”提示保留。
- **画面冲击与震动**：从暂停菜单挪进设置页，行为不变。
- **保存**：`user://settings.cfg`（网页由引擎写入浏览器本地存储）。键为 `audio/master|music|sfx|ambience`、`video/quality|fps_cap`、`hud/damage_numbers`、`feel/impact_effects`；旧版只有 `feel/impact_effects` 的文件照常读取，其余项取默认值。滑条拖动期间只标记待保存，关闭设置页或退出时写盘；开关按下即写盘。

### 手柄

- 设备分配（`scripts/journey_gamepad.gd`）：按设备号排序，本地双人时第一个手柄控制 01、第二个控制 02；单人和联机时第一个手柄控制本机角色，第二个不接管搭档。
- 映射：左摇杆或十字键移动（十字键优先；摇杆超过 0.45 量化成与键盘相同的 -1/0/1，走同一套固定步移动），A 跳跃，RT 或 RB 射击，X 换弹，Y 丢枪，Start 暂停 / 继续。手柄与键盘、触屏同时可用。
- 本地双人的 02 射击、换弹、丢枪沿用联机的战斗命令格式写入角色 1。
- 菜单：引擎默认的 `ui_up/down/left/right` 已包含十字键和左摇杆，用来切换焦点；默认 `ui_accept` 不含手柄，启动时补上 A，焦点按钮用 A 确认，滑条用左右调节；B 关闭设置页，暂停页按 B 继续。只在使用手柄时显示焦点描边，鼠标点击后的按钮外观不变。
- 与键盘的 `blocked_keys` 一致：菜单确认后仍按着的 A / 射击键要先松开才生效。
- 提示文字随最近使用的设备切换：开始页、暂停页、失败条和救援提示在手柄下显示 A / RT / X / Y / Start / B，按任意键盘键或鼠标键切回键鼠提示。

### 章节进度条

- `scripts/journey_chapter_bar.gd`：顶部两块 HUD 面板之间的 4 像素细条，金色填充为本章进度，六段分隔线与区域名（当前区域高亮），青色菱形标记最近存档位置。窄屏放不下六段文字时铺满顶部，只写当前区域名。奔跑、救援与暂停时显示，设置页打开时隐藏。
- 进入新区域（含每次出发的起始区域）时，屏幕上方显示“第 N 章 · 章名”和区域名：0.4 秒淡入，共 2 秒，最后 0.6 秒淡出。回到同一区域的存档不重复显示。
- 进度量化到 0.1% 才重绘，静止时不提交绘制。全部只读模拟状态，不影响联机同步。
