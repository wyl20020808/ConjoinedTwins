# 特效第四刀：环境氛围

日期：2026-10-20。分支：`feature/fx-hazards`（接第三刀 `10c1bf2`）。

## 改动

`journey_fx.gd` 新增三个常驻环境发射器，跟随两人中点前方，按章节时段开关（`sync_time_of_day`）：

| 章节 | 特效 |
| --- | --- |
| 一 清晨森林 | 林间花粉：自发微光的暖色小点缓慢漂浮，数量随林地权重变化 |
| 二 黄昏 | 萤火虫：路边低空黄绿色光点，湍流游走、明灭闪烁 |
| 三 夜晚 | 贴地薄雾：大而淡的雾团贴路面缓慢横移，被头灯与火把照亮 |

原有的森林落叶、村庄浮尘、矿道余烬不变。网页与移动端数量减半。

## 验证

- `check_journey_performance.py` 26 项通过；生产入口 headless 退出码 0。
- M4 1080p：森林 13.6–13.8 ms、村庄 9.2–9.5 ms、矿道 8.5 ms、设施 7.5–7.6 ms。与第一刀后相比，各段增加 0.5–1.4 ms，都在 60 帧预算内。
- 截图：`builds/round2/fx-amb/`（`zsheet.png` 为三章局部放大）。
