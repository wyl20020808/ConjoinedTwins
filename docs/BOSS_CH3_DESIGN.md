# 第三章 Boss 设计：海神波塞冬

日期：2026-10-23。任务分支：`feature/poseidon-boss`，从 `feature/dragon-boss`（第二章魔龙第二轮调整之后）创建——它复用魔龙分支里三章共用的 Boss 分派、飞行小怪与水母模型，因此须在魔龙分支合入之后（或一起）合入。本文是设计依据与实现记录；可见 GUI 试玩、真实手感与声音仍待用户验收，不得把设计目标当作已验收事实。

## 1. 定位与取舍

用户需求：第三关 Boss 按前两关同样的逻辑做一个海神波塞冬——从水面出来，以水为攻击，有小怪，悬空的神。

沿用前两章已验证的框架（场地 1800 单位、开战线与开战存档、失败从入口重打、护甲 25% / 硬直 100%、三阶段 65% / 30%、每轮若干招后给破甲窗口、Boss 镜头与射程加成、定时补给、入场锁操作与跳过），只替换“这只 Boss 是什么”：

| 沿用 | 海神特有 |
| --- | --- |
| 场地、站位上限、护甲、阶段、补给 | 场地尽头是遗迹深潭，海神悬浮在潭上方约 3.5 米，左右缓慢漂移、上下起伏 |
| 入场电影、跳过 | 潭水翻涌、旋涡扩大 → 破水升起 → 举矛引雷、标题 → 顿矛掀起水环 |
| 每轮 2/3/3 招后破甲窗口 | 招式：三叉激流、巨浪缺口、涌泉与旋涡水洼、召唤水族、怒涛震环；破甲：让能量绳横穿潮汐之心 |
| 三阶段场地限制 | 三阶段两侧海水漫上道路（贴边每秒扣 10） |

破甲方式刻意用本作核心的“能量绳”：两人分站水球两侧，让连着两人的绳子穿过水球。第一章是绕柱缠绳、第二章是双人踏板，第三章把“绳子的位置”本身变成目标。

## 2. 概念

- **名称**：海神波塞冬，副标题“自遗迹深潭升起的怒涛之主”，位于第三章“矿道归航”终点（归航出口）。
- **外形**（Tripo 生成）：白须白发、金冠、裸露肌肉上身配金色肩甲与腰带、青绿披风与长袍，右手握金色三叉神矛，悬空、双腿后屈下垂。模型放大 16 倍，约 15.7 米高（固定远景镜头下才压得住场面）。
- **弱点**：胸口海神之心。平时被神甲覆盖（25% 伤害），被震落水面时暴露发白光（满伤害）。
- **场景**：深潭水面（着色器动画、入场与凝聚时出现旋涡白沫）、潭边白沫、潭后的海底神殿遗迹（Tripo 生成）。

## 3. 场地

逻辑坐标（20 单位 = 1 米），场地入口 `S = 章节长度 − 1800`：

- 开战线 `S + 300`；深潭从 `S + 1440` 开始；海神悬浮在 `S + 1600` 上方 70 单位，在 x = ±110 之间按 `sin(0.33·t)` 漂移。瞄准点为胸口（离水面约 14.5 米）。
- 海神存活时两人最多前进到 `S + 1380`；场地内可后退到 `S + 120`。
- 潮汐之心水球落点 `S + 1000`，x 在 ±90 之间摆动。
- 入口：冲锋枪（左）与霰弹枪（右），两箱弹药、两个医疗包；之后补给节奏同前两章。

## 4. 战斗流程与数值

- 血量 **2400**，神甲 25%，被震落（硬直 7 秒）时 100%。
- 前摇倍率 1.0 / 0.88 / 0.75；每轮 2 / 3 / 3 招后必定凝聚潮汐之心；换阶段先怒吼 2.2 秒（伴雷光）。

| 阶段 | 血量 | 招式池 |
| --- | --- | --- |
| 一 | 100%–65% | 三叉激流（1 道）、涌泉（4 处）、巨浪（1 道）、召唤（2 只水母） |
| 二 | 65%–30% | 激流 2 道（各瞄一人）、巨浪 2 道（缺口换位）、加入怒涛震环（1 道） |
| 三 | 30%–0 | 激流 3 道（加一道瞄两人中点）、涌泉 7 处、水洼更久、震环 2 道、召唤加一只河岸钳甲兵；两侧海水 |

## 5. 技能

所有伤害走现有 `Combat.hit`：享受护盾、受击无敌，血量耗尽回存档点。

| 技能 | 前摇 / 预警 | 判定 | 伤害 | 躲避方式 |
| --- | --- | --- | --- | --- |
| **三叉激流** | 1.3 秒举矛，地面亮起从海神脚下指向目标的直线（跟人走），锁定后 0.5 秒射出 | 贴地水柱 0.7 秒，半宽 30，长 85 米；齐腰高跳不过 | 28 | 锁定后横向让开（0.5 秒够横跑约 90） |
| **巨浪** | 1.4 秒横挥，地面亮起一条绿色安全通道（缺口） | 整面水墙以 520 单位/秒从潭边推到场地入口，只有缺口（半宽 72）不伤人；跳不过 | 30 | 两人一起钻进缺口。缺口开在两人中点另一侧；二阶段起 1.6 秒后第二道浪，缺口再横移 150–210 |
| **涌泉** | 1.1 秒双臂上扬，圆圈跟着两人走，出手锁定 | 0.9 秒后水柱喷出，半径 66 | 22 | 锁定后离开圆圈；落点留下旋涡水洼 3 秒（三阶段 3.9 秒），踩上每秒 8 |
| **召唤水族** | 1.2 秒张臂长啸 | 潮汐水母从潭边浮起（2/2/3 只；三阶段再加 1 只河岸钳甲兵）；场上超过 5 只时跳过 | 水母水弹 14 | 先把小怪打下来。水母射程 380（短于枪的 400），必须飞近才能出手，也就能被还击 |
| **怒涛震环**（二阶段起） | 1.1 秒双手举矛，脚下圆圈亮起 | 神矛顿向水面，水环 700 单位/秒扩散，半宽 26 | 28 | 环到脚下时跳起；三阶段两道相隔 0.7 秒 |
| **潮汐之心**（破甲机会） | 1.0 秒双手高举凝聚水球（雷光一闪），1.2 秒水球落到场地中段并左右摆动 | 两人都落地、分在水球两侧，且能量绳（实际折线）离球心小于 36 → 累计 2.8 秒，水球炸开、海神被震落水面（硬直 7 秒，海神之心暴露）；绳子不穿过时进度每秒回落 0.4 秒 | 水弹 16 | 每 3 秒朝两人轮流掷水弹（飞行 1 秒、地面圆圈），被瞄的人侧身让开再回来 |
| **海啸**（凝聚失败） | 14 秒内没完成；最后 1.6 秒警示 | 全场水环 820 单位/秒 | 32 | 跳起 |

## 6. 入场动画（约 13 秒）

| 时间 | 画面 | 声音与特效 |
| --- | --- | --- |
| 0–1.2 | 黑边滑入，镜头从游戏视角转向深潭 | 远处闷响 |
| 1.2–4.5 | 低机位推近潭心，潭水翻涌、旋涡越转越大 | 激流水声（低音）、镜头轻颤 |
| 4.5–7.0 | 海神从潭底破水升起（蜷身 → 舒展），4.6 秒水柱与水花冲天，镜头仰拍跟上 | 巨浪拍击、水花、猛震 |
| 7.6–10.0 | 举起三叉神矛，8.4 秒天雷劈在矛尖、强光一闪，标题浮现 | 雷声、海神怒吼 |
| 10.0–11.8 | 神矛顿向水面，水环向外扩散，镜头拉远 | 巨浪拍击、最强震动 |
| 11.8–13.0 | 镜头平滑落回 Boss 战镜头，黑边退出 | 跳过时补一声怒吼 |

入场期间两人不能移动、开火，不受伤害，海神不能被锁定；0.8 秒后任一人按跳跃跳到镜头交还段。入场时间由模拟时间驱动，联机两端一致。开场运镜的“巢穴地下震动”对海神不触发（潭水翻涌由海神画面负责）。

## 8. 特效（程序生成）

- 深潭水面：两层滚动噪声扰动法线的半透明青色水面，`churn` 参数控制旋涡白沫（入场、凝聚、倒下时增大）。
- 流水着色器：沿 UV 流动的条纹与噪声，用于激流水柱、巨浪水墙、涌泉水柱、潮汐之心水球与两侧海水。
- 旋涡水洼：螺旋条纹着色器圆盘。
- 水花粒子：沿用魔龙火焰的面片着色器，换成青白色渐变并加重力；一次性水花（`Burst`）为 one-shot，避免重启后一直喷。
- 预警：激流直线（`boss_telegraph` 横带，沿锁定方向）、巨浪缺口通道（绿色横带）、涌泉与水弹圆圈、震环与海啸警示圈、水球落点圈。
- 雷光：从天上劈到矛尖的亮线与 0.25 秒衰减的强光，入场、凝聚、换阶段与破甲时出现。

## 9. 实现结构

- `scripts/journey_poseidon.gd`：海神模拟（纯数据、固定步、可存档、联机一致）。`body_pose()` 是模拟时间的纯函数（潭底、升起、悬浮漂移、震落、沉没），画面与瞄准点共用。
- `scripts/journey_boss.gd`：`CHAPTERS` 加入第三章；`module()` 按 species 返回魔龙或海神脚本，`add / advance / hint / skip_intro / title` 统一分派。
- `scripts/journey_boss_view.gd`：`special_view()` 按 species 加载魔龙或海神画面脚本。
- `scripts/journey_poseidon_view.gd`：海神画面（只读模拟）。
- `scripts/journey_monsters.gd` / `journey_enemy_view.gd`：潮汐水母（远程、飞行）沿用魔龙分支加入的飞行小怪表现。
- `scripts/chapter_catalog.gd`：第三章简介与提示加入 Boss。

## 10. 实现记录（2026-10-23）

### 执行者自测

- `tests/journey_poseidon.gd`：527 项 0 失败（布局、开战存档、入场锁操作与跳过、潭底与升起、悬浮漂移、护甲与锁定、激流命中 / 锁定后让开 / 二阶段两道、巨浪命中 / 钻缺口 / 跳不过 / 二阶段跟换位缺口、涌泉与水洼、召唤、潮汐之心站一侧不计 / 横穿成功震落 / 硬直满伤害 / 水弹 / 海啸跳躲与命中、震环跳躲与命中、三阶段海水、重打、沉没与通关）。
- `tests/journey_poseidon_playthrough.gd`：两名脚本玩家只用输入从场地入口打到终点结算（约 202 秒、7 次破甲、4 次巨浪）。调试中据此做了三处平衡：激流锁定后到射出由 0.25 改 0.5 秒；钳甲兵只在三阶段召唤、血量 2600 改 2400；潮汐水母射程 640 改 380（原射程超过枪的 400，打不到还击）、伤害 22 改 14。
- `build-tools/poseidon/capture_poseidon.gd`：真实渲染截图核对入场（翻涌、破水、雷光、标题、顿矛）与各招式。
- 网页版字体子集缺“铠”等字，界面文字改用“神甲”；三叉神矛在游戏文字里写作“神矛”（子集没有“戟”）。
