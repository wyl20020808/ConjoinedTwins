# 第二轮画面 · 第四刀：第三章夜间矿道与设施

日期：2026-10-20。分支：`art/night-mine`（从第三刀 `art/energy-rope@e9a8a87` 继续）。

## 问题

第二刀把第三章改成了夜晚，但月光下它的白盒感更明显：

- 矿道两侧的大石块用的是铺地石材质，表面是方砖纹，看起来是一团深色、没有细节的块。
- 路边地块是纯色平面，夜里像一块灰板。
- 设施段的厂房是一排扁平的蓝灰盒子，夜里没有任何光，轮廓消失。
- 路面在夜里只是更暗的铺装，没有夜景该有的反光层次。

## 改动

- **路面**（`journey_ground.gdshader` 新增 `night`，只在第三章的矿道、遗迹、设施段打开）：
  - 积水范围扩大，路面去饱和并压暗，火把与月光在水面反光；
  - 两条矿车轨道（距中线 7.2 米、轨距 1.1 米）贯穿路面：钢轨半金属反光，枕木压暗。
  - 轨道只是路面着色，不是模型，不参与碰撞。
- **岩体**：改用 `rock_face_03` 三平面岩面，不再出现方砖纹。
- **发光矿晶**：每三块岩石配一簇，放在路缘外 17.9 米，4–7 根六棱锥，青、紫、绿三色轮换。HDR 自发光，加一盏不投影的小灯，写入体积雾。
- **路边地块**：矿道、遗迹、设施段改为碎石岩面。
- **厂房**：
  - 朝路一面两排窗灯，冷白为主、约两成暖黄、四成熄灭；
  - 屋顶一盏红色航空信标，周期闪烁；
  - 路侧一盏冷白泛光灯打亮墙面，夜里厂房有可读的轮廓。
- 以上全部是展示层，不参与碰撞与危险判定；灯光不投影，70–110 米淡出。
