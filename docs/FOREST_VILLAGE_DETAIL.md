# 森林与村庄细节更新

日期：2026-10-15。任务分支：`feature/journey-terrain-polish`，继续此前地形与怪物成果，原始基线为远端 `test` 的 `3ee7185`。本轮未合并、推送或发布网页。

## 实际改动

- 森林增加带树根的树桩、倒木、苔石、蕨类与小蘑菇。树冠改为较小的多组叶簇，调整树干可见比例、叶色与远近层次。
- 村庄增加条纹遮阳摊位、蔬果箱、陶罐、带长凳和盆栽的门廊、菜圃与灯笼。村庄树带后移，房屋不再被近处树冠大面积遮挡。围栏沿道路摆放，新增布景位于可行走道路外。
- 第一、二章村庄统一使用灰泥墙面、红褐瓦顶和共享材质；第二章房屋也进入 MultiMesh 批次，避免逐屋重复加载带贴图的模型。
- 林间道路以踩实泥土为中心，路肩保留落叶；村庄混合石板与泥土。压低纹理高频噪点，加入湿润色差、宽缓林下遮光和树根、建筑接触暗部。调整环境亮度、太阳色温与雾色。
- 保留固定朝向镜头、真实地面缺口、后退、战斗、血条及换弹规则；未修改玩法模拟与网络协议。仍为当前低面数美术方向，尚未达到照片写实。

八份原创布景合计 342,932 字节，使用本机 Blender 后台生成，不添加大型贴图和动态灯。来源、生成器和哈希见 `ASSET_SOURCES.md` 及 `build-tools/journey/set-dressing-assets.json`。

## 性能边界

继续使用空间批次、距离 LOD、后台区块计划和资源回收，Web 不恢复全景动态阴影。草丛候选数由每侧每区块 650 降至 420；树候选数由 115 降至 85。更细树冠增加了单树面数：近景 2,520、远景 1,080，不能据此声称本轮所有场景 GPU 开销下降。
