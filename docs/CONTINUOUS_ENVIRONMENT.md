# 原场景延伸、连续森林村庄与机关节奏

2026-10-15，本轮在 `68d6ba0` 的加载优化、单人人机、武器战斗及远程联机上继续开发，保留这些入口。

## 连续行程

第一章仍为同一张连续地图，全长 1920 米。开场保留石板道路、山脊岩壁和远处石峰；220–420 米逐渐接入陆地与树林，420–1020 米为完整森林；1020–1250 米树密度渐减、院落与房屋渐增，进入村庄后继续行走至本章出口。距离按真实世界坐标连续累计，不为进入森林、村庄重新加载一关，也不瞬移角色。

道路与侧边地形使用相同的世界坐标贴图、地貌权重及连续高度函数，区块接缝复用边界采样。地面从石板混入落叶与泥土，再渐变为村庄路面；路旁不再是两块独立纯色色板。树木分为近景完整网格和远景低面数网格，蕨类、灌木、草丛、水井、木柴、木桶、晾衣绳和前后两排住宅组成环境层次。光照、雾和实录鸟鸣随林地权重渐变；镜头方向固定。

乔木、林下层和生活道具由 `build-tools/journey/make_landscape.py` 在 Blender 后台生成。静态资源合并为单网格，再通过 MultiMesh 实例绘制；区块纯数据规划继续使用已有工作线程或无线程分帧路径，地形按 8 米条带逐次安装。

## 核心机关与频率

使用 `journey_encounters.gd` 按 20 米布置一个途中交互节拍。空手 8 米/秒时约 2.5 秒，持枪速度为 6.8 米/秒时约 2.94 秒。这里是持续向前时的距离节奏，不会在玩家停步、跳跃或等待合作时强制每三秒刷危险。

第一章 74 处途中机关/危险与 7 道合作门，包含 20 种途中类型。第二、三章各有 58 处途中机关与 5 道合作门。合作门前后让出站位与退出空间，这部分由正在操作的门、踏板和桥承接节奏。

旧机关实际复用原有物理与展示实现：旋转扫杆、摆锤、落石闸、蒸汽喷口、往复横扫、活塞、升降平台、坡道、台阶和倾斜桥面。低栏、高柱、巨岩、活动地刺、断口、塌陷地面、倒树、冲锋兽、投掷、推车和摆木分散编排。三次途中节拍使用同侧安全走廊，下一组换侧；避免相邻两处要求没有反应时间的全路横穿。

途中合作门包括原野石门、林间踏板木桥、古树林门、村口供能闸与院落双板防线，终点继续保留供能、双板和吊桥。桥面支撑与开门时间来自真实机关状态。人机仍输出正常方向和跳跃输入，不改坐标、生命或碰撞。

## 手机稳定性处理

用户反馈为手机浏览器游玩一段后自动刷新/退出，未取得该设备系统的终止日志，不能声称已经确认唯一根因。已核实的主要负担是大量 3D 贴图以未压缩格式进入显存，及多个 GLB 各自重复引用相同纹理。

本轮对普通 3D 图像启用 VRAM 压缩；HDR 天空保持通用的无损格式，导入上限改为 1024，避免要求手机支持 HDR 块压缩。通过场景后置导入脚本，将石材、木板与树皮统一引用项目纹理，清除多余 ORM 通道引用；Web 导出排除已无运行依赖的重复纹理、历史机甲和旧飞行道具。原始素材保留。共享纹理检查覆盖房屋、门、吊桥、推车、栅栏、倒树与水车。

区块资源队列只保留当前窗口、预备区块和近处动态事件所需引用。手机端提前加载范围缩短，近景树使用完整叶片，远景低面数，3D 渲染比例为 0.75，关闭 MSAA，阴影范围为 65 米；HUD 不随 3D 分辨率一起缩小。只读 `?verify=1` 状态中加入显存、纹理、缓存和区块数量，便于后续比较。

密集关卡的地面支持采样复用相同物理时刻的完整缺口集合，并索引地形类型，减少绳索重复扫描；没有按距离删除有效物理机关，专项将优化后的结果与全量解析判定逐点比较。

联机协议升为 4，双方必须刷新网页，旧原生包需要重新导出。生产网页仍由原入口、Caddy 与专用中继提供。

## 验收与边界

- `journey_encounter_density.gd` 检查节拍覆盖、实际类型数、合作门分布、奖励上限、连续地貌，以及索引后的地形与全量解析判定一致。
- `journey_density_campaign.gd` 只给真人离散方向输入，人机自主操作；验证各章真实通关、全门开启、生命、绳长和不后退。没有改角色位置、关闭碰撞或直接置门为已开。
- `journey_environment_lifetime.gd` 是展示层资源生命周期巡检，通过移动观察位置覆盖三章与重试，不能作为合法通关证据。
- `environment_review.gd` 与 `web_environment_review.cjs` 用独立测试工程运行实际 WebAssembly，采样两轮完整第一章展示、存储截图和 GPU 计数。它同样是展示巡检，不能替代玩法路线测试。手机模式为隔离 Chromium 的触控模拟，不是 iPhone Safari 真机。
- 当前执行者自测：密度与完整地形等价检查 217 项通过；三章人机路线分别以 20799 / 16283 / 16037 个 60Hz 输入帧到达结算，7 / 5 / 5 道门全部开启，生命均为 100，最小前向位移为 0，最大绳长均不超过 7.33 米；WebSocket 与混合客户端至少 420 个共同帧一致。单人基本行为 372 项通过。
- 原有 `journey_events.gd` 的“野猪/石块接触立即共同失败”两项，在未修改的 `68d6ba0` 上也失败：战斗版本已改为生命伤害。本轮保留这些历史断言，不将其改判通过。旧 `journey_headless.gd` 中“每章恰好两道门”的断言属于本轮明确扩充的旧数量契约。
- 播放音频的 headless 场景短测试在退出时仍可能报告 WAV/OGG 播放句柄未及时回收；这与实际运行中资源持续增长分开记录。展示层 headless 生命周期巡检退出还有一个 DummyMesh RID 清理警告；浏览器没有对应脚本错误。不得声称全部旧测试或退出检查均零警告。

执行者自测日志与图像位于被忽略的 `build-tools/journey/evidence/environment/`。Controller 独立测试未运行（`tests=[]`）。可见桌面 GUI 与手机真机的触屏、音频、帧率、连续游玩稳定性仍待用户试玩，记为 `deferred_by_work_mode`。手机原故障没有设备终止日志，当前只能证明已降低资源负担并通过所列测试。
