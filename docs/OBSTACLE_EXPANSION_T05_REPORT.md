# 八类障碍三关整合实施与验证记录（t05）

日期：2026-10-13。沿用 Run `6377e8b8-0915-462e-8cd5-50e0de0ad7d6` 的现有成果，仅实施 t05。执行者自测与原生独立 B 审查均通过；配置的 PersonalAgent 决策者验收仍须由 Controller 接续调度，不以本记录代替。

## 实际改动

- `scripts/road_templates.gd`：八类教学进入三关实际生成序列。第一关保留扫杆和缺口的全部进阶；后两关优先整合既有身体高度障碍、跳跃、错峰及双威胁。先独立教学，再启用仅有的 `pillar_press`、`low_steam` 白名单组合。高速滚球、火箭与新障碍分时串联；未标注或禁区组合被拒绝。
- 分段长度仍为 840；首段距离从 600 改为 500，前向预生成范围从 3360 改为 840，缩短空跑并限制预生成工作量。三关各 100 秒，未通过缩短结算时间制造密度提升。
- 金币按已验证共同路线的实际地面支撑位置形成规则链，跳跃期间不在不安全落点放币。编号、实际领取、段间间距与池上限分别检查；奖励固定池从 24 调整为 64，危险池上限 32。
- `scripts/road_run.gd`：捕获真实入口、角色高度与输入缓冲、相位、支撑、绳段及接触状态；回退复用同一入口验证，教学失败不被安全段吞掉，验证失败停止生成并留下原因。重试先完整复位；线程在重试、结算和退出时取消并 join。
- 生产场景启用后台路线验证。证书证明的是提交入口路线；安装时另存实际入口，并验证共同横移、前后归队、落地及剩余预警时间。实际入口不足以完成共同归队时拒绝安装。此准入不宣称对任意玩家操作重新完成整段路线证明。
- 缓存绑定最终源码字节、速度、布局、完整入口与支撑规则，最多 32 项。新增保守碰撞宽阶段剔除；附近障碍、绳段及已有滚球接触仍走原连续检测。
- `scripts/road_levels.gd`、`scripts/road_demo.gd` 同步奖励池和生命周期；新增当前验证入口与证据审计工具，更新 README、开发方案和障碍设计文档。

保持此前已验收的提速：两玩家移动速度 160 单位/秒（8 米/秒），道路基础推进速度 140/160/180，关卡倍率 1/1.08/1.16；生产跑动动画倍率约 1.28–1.35，普通首关 1.3。跳跃初速 240、重力 800，连接上限 146.6。没有重做 t01–t04，也未改写历史输入记录。
