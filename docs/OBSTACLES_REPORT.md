## 生产改动

`road_run.gd` 在实际 450 米生产路线接入高货箱、低栏、固定地刺、活动地刺、高位扫描束、飞行物六类，其中飞行物分低位、身体高度、高大三型。前八组逐类教学，后续重复排列，保留右侧双人绕行通路。飞行物都是致命危险，没有拾取逻辑。四向输入与独立跳跃沿用 t01，没有低姿态要求。

集中危险数据包含地面矩形、底/顶高度、周期、预警、危险持续时间和飞行轨迹。活动地刺/扫描束周期 4 秒：预警 1 秒、危险 1.5 秒、安全 1.5 秒；地刺伸出/回落各 0.25 秒，高度同步变化。飞行物提前 1 秒预警，横向运动 1 秒，生产速度 16 米/秒；教学轨迹朝左侧退出，保留右侧联合通路。

角色高度 58 地面单位（2.9 米）。固定步子步将玩家地面线段、跳跃高度与飞行物相对运动统一到同一时间参数进行三维区间求交，避免仅检查地面矩形、漏判高速穿越，或将不同时刻高度与地面接触错误组合。共同失败包含命中角色及具体危险应对说明。所有周期和轨迹直接由本轮 elapsed 求值，重试恢复到零，无残留异步计时器。

`road_demo.gd` 使用同一危险采样驱动模型位置、危险高度、显隐、文字与颜色预警。低栏有横杆标识；地刺使用尖锥及半透明危险包围体，显示完整矩形危险范围；扫描束和身体高度飞行物为紫色高位体积，飞行物具有前灯和预警轨迹。绿色安全、黄色预警、红色危险同时配文字说明。模型与危险矩形/高度共用尺寸数据。

动作反馈增加 Takeoff、Air、Land 与方向输入状态；Jump 动画按物理抛物线阶段采样，落地恢复 Run 混合；短暂落地阴影扩散、方向倾斜反馈与真实高度阴影同时显示。继续播放原骨骼 Run，不使用静态滑行代替奔跑。受击至 Death 的共同失败过渡保留，连线端点跟随角色三维高度。

README 已更新危险尺寸、应对、预警/周期和测试入口。无限道路、难度与多种子公平生成属于后续任务，本次没有宣称完成。
