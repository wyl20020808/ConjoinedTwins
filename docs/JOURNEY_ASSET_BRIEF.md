# 连续旅程：写实素材需求与制作规格

本轮目标为固定纵深镜头下尽量真实、清晰的森林、乡村、河谷和矿道。当前角色与部分植被仍是既有风格化素材；接入扫描材质和 Blender 资源后也不能直接称为照片级写实。真实运行画面、材质比例、遮挡和性能需要另行验收。

## 已取得、正在使用

- Quaternius：两名冒险者，带 Idle、Run、Roll、受击与死亡动作；松树、枯树、灌木、草和遗迹装饰。沿用项目已有 CC0 来源记录。
- Poly Haven：已有石板、岩石和天空；本轮补充 Forest Leaves 02 与 Wood Planks 的 1K 颜色、OpenGL 法线和粗糙度贴图。CC0，六份文件合计约 2.64 MiB，逐文件 SHA-256 见 `build-tools/journey/material-sources.json`。
- Kenney：现有工业建筑用于设施区远景，沿用 CC0 来源记录。

## Blender 制作清单

制作脚本：`build-tools/journey/make_assets.py`，仅后台建模、动画和 GLB 导出，无需渲染或操作桌面。

| 资源 | 制作内容 | 动画与运行要求 |
| --- | --- | --- |
| 三种村舍 | 石基、抹灰墙、木骨架、屋瓦、门窗、烟囱，其中一种带门廊 | 静态，统一米制比例；门窗不做室内场景 |
| 村民动作 | 对既有 CC0 角色新增骨骼动作，原文件保留 | Throw：抬手、蓄力与投掷；Push：双手推动 |
| 野猪 | 躯干、肩背、长鼻、獠牙、耳朵、鬃毛、四肢 | Charge：四肢交替与躯干起伏；冲锋位置由游戏物理决定 |
| 木推车 | 车板、车轮、辐条、把手、麻袋 | WheelTurn：轮子转动；横穿位置与碰撞同源 |
| 可倒伏松树 | 树干、枝条、树冠，根部旋转支点 | Fall；游戏按预警与砸下时间驱动，落地后保留实体 |
| 水车 | 轮缘、辐条、桨板、轴与轴承支架 | WheelTurn；供能出口配套装置 |
| 木栅门 | 石柱、横梁、木栅和铁箍 | GateOpen；开门后锁存 |
| 吊桥 | 木板、承重梁、栏杆、绳栏、近端铰点 | BridgeLower；放平后才提供真实支撑 |
| 木围栏、路牌 | 统一木材与比例 | 静态环境补充 |

GLB 使用三角面、UV 和可导出的 Principled BSDF 材质。贴图随资源嵌入；木板使用颜色、法线和粗糙度。保留脚本与原始第三方贴图，生成清单记录输出字节与 SHA-256。

## 建议用户优先寻找的高质量素材

这些资源用于进一步提高真实感，不阻塞现有玩法开发。优先购买或下载同一作者、同一系列，减少风格与材质精度不一致。

| 优先级 | 需要的素材 | 数量建议 | 必要条件 |
| --- | --- | ---: | --- |
| P0 | 写实野猪，或同等级森林动物 | 1 套 | 骨骼、Idle/Walk/Run/Charge，冲锋原地动画；不要求游戏根运动 |
| P0 | 写实乡村村民 | 3–5 人 | Idle、Walk、Throw、Push；服饰时代与村庄统一 |
| P0 | 欧洲乡村或山林村庄模块包 | 1 套 | 3–5 种房屋、屋顶、门窗、围栏、摊位；PBR，外景即可 |
| P1 | 写实树木和林下植被 | 1 套 | 至少 3 种树形、草、蕨类、灌木、枯木和树桩；透明裁切与 LOD |
| P1 | 自然环境音 | 每类 2–3 条 | 森林风、鸟鸣、河水、村庄远声、木头开裂、猪叫；可循环或独立短音效 |
| P1 | 主角替代或升级资源 | 2 人 | 与村民同一真实度；跑、跳、落地、受击、死亡及救援动作 |
| P2 | 河岸、矿道和设施模块 | 每类 1 套 | 石岸、桥、矿洞支架、矿车、轨道、铁门和管道 |

推荐交付格式：GLB/glTF 优先，FBX 或 `.blend` 也可；贴图包含 Base Color、Normal（OpenGL）、Roughness，金属物再加 Metallic。近景主资源先以 2K 贴图为目标；远景 1K。树木建议提供 LOD，单株主 LOD 尽量控制在约 5千–3万三角面；角色约 2万–6万三角面。这些是初始预算，最终按实际性能与镜头占屏面积调整。

许可必须允许用于游戏及随安装包分发处理后的资源。请同时保留商品页面、作者、许可原文、下载文件名和购买凭证。模型浏览页面截图不能替代源文件。无需提供账号或密码。

## 沉浸感验收

1. 同一区域的光源、材质粗糙度、尺度与色温一致，远近层次清晰。
2. 树木、房屋和烟雾不遮住角色、绳索、危险和落脚点。
3. 预警通过树叶晃动、草丛动静、村民动作和声音表达，同时保留清晰的地面范围提示。
4. 静止玩家不会让道路或镜头自动推进；镜头只有平移跟随，朝向不变。
5. 暂停、重试与存档恢复同步冻结或还原危险相位和动画；视觉和碰撞对应。
6. 画面、自然音效和手感以实际运行与双人试玩为准；headless 检查不代表这些验收已通过。
