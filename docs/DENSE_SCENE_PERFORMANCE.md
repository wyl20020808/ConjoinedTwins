## 改动与规则

- 机关按类型建立可失效索引，保留源列表顺序；种类变化会重新分类。位置、运动相位和高度仍实时读取，移动球体与既有绳索接触继续精确采样。
- 绳索每次求解前准备碰撞体的半径、高度和扩展盒边界，投影时复用。半径保留双精度，碰撞体次序、投影计算与边界比较保持原值。
- 搭档同一次避险决策的多个候选方向，共用相同未来时刻的机关和动物几何预测；各方向的路线、地面支撑、跳跃与绳长检查仍分别执行。
- 动物攻击与射击视线先按类型和保守包围盒排除不相交实体，再执行原高度线段遮挡算法。
- 敌人命中闪白只在状态变化时更新材质；血条形状和颜色只在生命值改变时更新。模型、命中反馈、锁定与动画均保留。
- 本地和网页都在绘制帧提交最终视图；一个绘制帧内追赶多个物理步时，不重复提交整套机关、动物、网格与 HUD。

未减少生产场景的机关、动物或环境密度；固定物理步长、每步三个运动子步、绳索粒子数与十二轮约束迭代均未改变。未关闭碰撞、阴影或伤害，也未限制物理追赶步数。

原生 FPS 部分已由后续 [帧率根因复核](FRAME_RATE_ROOT_CAUSE.md) 修正。首轮隐藏窗口的常规运行、救援状态与 CPU 调度条件没有充分分开，其 36–45 FPS 不应被解释为这台机器或项目可达到的帧率上限。原始数据保留供追溯，不再用于高帧率能力判断。上表固定种子 headless CPU 前后比较仍保留其原有测量边界。

穿林入村的该轮原生基线被游戏自身焦点通知暂停，结果无效，不用于前后收益比较。首轮原生测量曾与其他测试重叠，同样不计入正式数据。随后串行复测，相关原始日志均保留。独立手动视图夹具另在运行态保存三章前后实际渲染截图，不以该夹具替代真实运行帧率。
