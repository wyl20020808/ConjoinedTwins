# iPhone / iPad 联机试玩说明

适用范围：两人在不同地点，各用一台 iPhone 或 iPad，经你电脑上的联机服务器合作游玩。仅供个人试玩，不上架。

## 玩法与操作

- 每人控制一个角色：先连上服务器的是 01，后连上的是 02。
- 左半屏：手指按下即出现摇杆，按住滑动控制移动方向（吸附 8 方向）；松手停止。
- 右半屏：点击跳跃；关卡结算时点击右半屏确认。
- 右上角“暂停”按钮暂停或继续，任一方操作对两人同时生效。
- 电脑客户端同样可以联机，用 WASD 或方向键移动，空格或回车跳跃。

## 联机原理（帧同步）

- 服务器（`scenes/net_relay.tscn`）不运行游戏逻辑，只按每秒 60 帧把两人的输入和命令（开始、暂停、重试、难度）打包广播。
- 两台客户端用同一个种子、同一串帧各自模拟，所以地图、跳跃和失败判定完全一致。联机模式下，后台地图证明按道路位置的固定时机安装，重试种子也由确定公式推导，不依赖设备快慢。
- 客户端每 60 帧上报一次状态指纹；服务器发现两端不一致时会提示“画面不同步”。
- 网络协议：ENet（UDP），默认端口 24680。两端版本号不同时拒绝连接。
- 已知限制：队友断线后对局暂停，重新连上会从第一关重新开局，不支持断线续玩。操作延迟约为一次网络往返时间，没有做本地预测。

## 启动服务器（你的 Windows 电脑）

双击项目根目录的 `启动联机服务器.cmd`。窗口里显示“联机服务器已启动，UDP 端口 24680”即表示就绪；关闭窗口即停止。玩的时候电脑需要保持开机，且这个窗口不能关。

如需换端口：

```
启动联机服务器.cmd -- --port=25000
```

## 没有公网 IP 时的连接方式

二选一。游戏代码不需要因此改动，只要填写对应的地址。

1. **组网（推荐先试）：Tailscale 或 ZeroTier**
   - 电脑和两台 iPhone/iPad 都安装同一个组网 App，并登录同一个账号或网络。
   - 在电脑上查到组网分配的地址（Tailscale 是 `100.x.x.x`），两台手机在游戏开始页填写这个地址，点“联机”。
   - 优点：不需要改路由器，电脑不暴露到公网。
   - 注意：打洞失败时流量会走中继，海外中继延迟可能达到 200 毫秒以上。如果明显卡顿，改用第 2 种方式。
2. **内网穿透：frp 或花生壳等**
   - 需要一台有公网 IP 的服务器（国内云服务器最便宜的档位即可）或付费穿透服务，把公网的 **UDP** 24680 转发到你电脑的 UDP 24680。
   - 注意必须转发 UDP，只转发 TCP 无法连接。手机填写公网地址（如 `1.2.3.4:24680`）。

Windows 防火墙首次运行服务器时，如果弹出提示，需要允许 Godot 访问网络。

## 安装到 iPhone / iPad（需要 Mac）

iOS App 必须在 Mac 上用 Xcode 签名后才能安装：

1. Windows 端导出 Xcode 工程：`python build-tools/prepare_ios.py`。脚本会先校验项目本地的官方 4.7.1 iOS 模板 `build-tools/cache/ios.zip`（来源与校验记录见 `build-tools/cache/ios-template-source.json`），再用导出预设 `iOS` 输出到 `builds/ios/`；旧工程移到 `builds/ios-history/`，日志写入 `builds/ios-evidence-<时间>/`。只想准备或校验模板时加 `--templates-only`。
2. 把整个 `builds/ios/` 文件夹拷到 Mac，用 Xcode 打开其中的 `.xcodeproj`。
3. 在 Xcode 的 Signing & Capabilities 中登录你的 Apple ID，选择你的 Team（导出时填写的 Team ID 只是占位）。
4. 用数据线连接 iPhone/iPad，选为运行目标，点击运行。首次安装后需要在设备的 设置 → 通用 → VPN 与设备管理 中信任你的开发者证书，并打开 设置 → 隐私与安全性 → 开发者模式。
5. 免费 Apple ID 安装的 App 7 天后失效，需要重新连接 Mac 运行一次。队友的设备也必须到这台 Mac 上安装。付费开发者账号（每年 99 美元）可以改用 TestFlight 远程发给队友安装。

## 导出环境准备状态

- 已准备：iOS 导出预设（`export_presets.cfg` 的 `iOS`，只导出 Xcode 工程，同时支持 iPhone 和 iPad，开发方式签名，Team ID 为占位，需要在 Xcode 中改选自己的 Team）、项目本地 iOS 模板和导出脚本。
- 尚未执行：实际导出、Xcode 编译、真机安装。游戏仍在迭代，需要试玩时再运行导出。
- 升级 Godot 时，iOS 模板和 macOS 模板必须一起更换并重新校验，规则同 [macOS 可重复导出流程](MACOS_EXPORT_WORKFLOW.md)。

## 验证状态

- 自动回归：`tests/online_lockstep.gd` 在本机起服务器和两个生产场景客户端，经 UDP 跑一段对局，核对两端状态一致、命令同步、断线处理，以及后台生成在不同线程快慢下逐帧一致。
- 未验证：真机触屏手感、iOS 安装、跨城网络延迟、Tailscale/frp 的实际连通性，需要用户试玩确认。
