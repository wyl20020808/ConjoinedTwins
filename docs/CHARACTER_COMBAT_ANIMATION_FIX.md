## 问题与处理

- 旧手部 IK 在上半身混合之前执行，最终画面里的肩膀、手腕和枪可能不一致。现在在 SkeletonModifier 的躯干、落地修正完成后再次完成接触求解，枪与手部目标共同跟随胸口位移。救援和死亡时关闭该步骤，保留原有救援骨骼覆盖。
- 肘部弯曲方向改为角色局部方向，避免转身后仍向世界固定方向弯折。枪械动作片段保留脊柱、胸口和头部表现，双臂由最终接触目标驱动，避免不同骨架的肩部重定向扭曲。
- 增加枪身坐标下的手腕方向、掌心握点补偿和手指弯曲；覆盖两名角色和四种武器。换弹空出的手继续沿原动作曲线移动。
- 跳跃由物理竖直速度选择起跳、腾空相位后停止动画自行推进，离地立即撤掉侧步层。跳跃片段不循环，保留轻重落地动作。
- 暂停时瞄准权重和后坐热度停止变化。

本轮复用现有 Blender 动作、模型和动作曲线，没有下载新资源，没有改变伤害、射速、换弹时长、碰撞或联机模拟。
