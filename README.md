## 危险与应对

各关按配置逐步加入危险，所有飞行物都是危险，不能拾取。角色碰撞体高度 2.9 米，危险底部与顶部均参与连续碰撞。

| 危险 | 危险高度 / 地面尺寸（米） | 应对 |
| --- | --- | --- |
| 高货箱 | 0–3.0 / 4×3.25 | 左右绕行 |
| 高柱 | 0–5.0 / 直径 1.2 圆柱 | 两人从同一侧绕行；分侧通过会让绳索绕柱 |
| 低栏 | 0–0.6 / 4×0.6 | 跳跃或绕行 |
| 固定地刺 | 0–0.5 / 4×0.6 | 跳跃或绕行，起跳与落地位置也须安全 |
| 活动地刺 | 0–0.8 / 4×0.6 | 跳跃、绕行或利用收回窗口 |
| 高位扫描束 | 1.3–2.5 / 4×1.2 | 四向绕避或安全时窗，不要求低姿态 |
| 低位迎面飞行物 | 0–0.5 / 2.8×1.2 | 独立跳跃或共同绕行 |
| 身体高度迎面飞行物 | 0.9–1.9 / 2.8×1.2 | 主要共同绕行；触碰绳段也会失败 |
| 石球 | 直径 4.5 / 球体 | 两人同侧避让；5 米/秒迎面运动 |
| 铁球 | 直径 4.0 / 球体 | 两人同侧避让；5.2 米/秒迎面运动 |
| 独立高速火箭 | 0.9–1.9 / 2×3.2 | 18 米/秒迎面运动；两人同侧避让，实际绳段命中同样失败 |

活动地刺和扫描束每 4 秒一周期：按难度预警 1–1.5 秒、危险 1.5 秒，其余时间安全。地刺伸出/回落各 0.25 秒。生产飞行物从前方持续可见并迎面接近，低位 9 米/秒、身体高度 11 米/秒。迎面预警按当前实际相对前向速度计算预计碰撞时间（TTC），提前量取难度配置与共同换边时间加 0.35 秒余量的较大值；普通初值约 2 秒。预警保存相对速度、TTC、换边时间与轨迹证据，锁定后不追踪玩家改道。模型、地面阴影和轨迹提示使用同一运动位置，角色与实际绕障绳段均做连续检测。历史横向飞行夹具仍可运行，不参与新的生产生成。

两种球复用同一机制及按类型回收的节点池，球体模型、碰撞半径与滚动路程同源，外观分别为粗糙石质与金属条带。球的接触圆随运动更新，绳索保存连续绕行侧，真实路径、张力和受阻反馈随之变化。绳长耗尽时球的运动驱动停在最后合法位置，不把角色强行拉过球；真实接触且约束耗尽持续约 0.8 秒共同失败。仅左右分侧、无接触不会失败；及时后撤可解围，能否解围仍取决于剩余前后空间，优先在预警时共同换边。绳索接触按实际高度区间内的最大球截面保守求解，并为跳跃全过程的最大截面预留长度；预留本身不伪造接触或单独累计失败。当前为平面切线/弧段及有界运动驱动，不含球质量、完整三维球面滑绳、弹性、摆荡或打结物理。
