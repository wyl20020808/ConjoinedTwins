# 共生连线 · 双人归航 Demo

两台机甲沿未来工业港道路自动前进，在同一键盘上合作避障。生产入口仅提供本地双人，无 AI 控制、模式切换或自动接管。固定纵深镜头，不旋转、不晃动、不突然变焦。

**Windows 启动：双击 `启动归航Demo.cmd`。** 或用 Godot 4.7.1 打开 `project.godot`，运行 `scenes/road_demo.tscn`。Agent 不自动打开游戏。

## 操作与规则

| 按键 | 行为 |
| --- | --- |
| WASD | 青色 01 四向移动；W 向前、S 向后 |
| 空格 | 01 跳跃 |
| 方向键 | 橙色 02 四向移动；上向前、下向后 |
| 回车 | 02 跳跃 |
| 空格 / 回车 / 开始按钮 | 开始页或失败页启动共同出发，不附带跳跃 |
| Esc | 暂停 / 继续 |
| R | 两人共同回到起点 |

没有趴下、爬行或二段跳。跳跃按下触发，长按不会连续起跳；落地前约 0.10 秒内按下会在落地后立即起跳，更早的按键作废。开始、暂停恢复及重试会屏蔽仍按住的旧输入，请松开后重新按下。

道路自动推进，生产入口现为三关本地双人。开始页仍选择简单/普通/困难，默认普通。双方四向手动移动速度 8 米/秒，斜向归一化；Run 动画约 1.28–1.35 倍，普通第一关 1.3 倍，仅跑动加速；两人各在推进中心前后 ±5 米内调节，实际间距仍受 7.33 米绳索约束。路面宽 24.6 米，角色中心横向边界 ±11.7 米。

| 关卡 | 内容 | 基础目标 |
| --- | --- | --- |
| 1 同侧归航 | 八类独立教学、扫杆/缺口进阶、随后两种白名单组合 | 100 秒 |
| 2 迎面协作 | 八类复习、身体高度物、两种滚球、火箭、错峰旧玩法及白名单组合 | 100 秒 |
| 3 连线接力 | 八类复习、旧双威胁与错峰练习、白名单组合及合作奖品 | 100 秒 |

各关速度为所选难度基础速度 × 1.00 / 1.08 / 1.16；简单/普通/困难基础速度现为 7/8/9 米每秒；终点距离等于关速 ×100 秒。普通难度约 800 / 864 / 928 米。回撤、受阻会延长实际时间，不设置时间失败。配置见 `scripts/road_levels.gd`。两人存活且地面位置都越过终点才结算；结算后先松开旧键，01 按空格、02 按回车分别确认，两人均确认后进入下一关；第三关确认后显示总成绩。结算期间 R 不重新领取奖励。

金币每个实例 +10 分；合作奖品每个实例 +100 分，前两关双方共同到位，第三关需角色中心分别进入互不重叠的前后光圈（角色可交换）。奖励按稳定实例编号记录，两人同时接触、跨帧接触和节点槽复用不重复计分。团队护盾最多一个，吸收一次角色危险伤害，提供 1 秒团队无敌；满盾时不会拾取叠加。吸收过的同一稳定碰撞事件不能再次消耗新护盾，无敌到期后仍在该危险中会失败。绳段命中、绕柱几何受阻和滚球带绳不受护盾保护；免伤也不允许穿过高货箱或高柱。

暂停冻结推进、跳跃、奖励、危险和无敌计时，保留接触以便原位继续；恢复屏蔽旧输入。R 或失败页重试当前关，关号与种子不变，本关金币、奖品、护盾和碰撞去重清零，已完成关成绩保留，因此失败不能累计刷分。重新开始三关清空全部成绩。评价规则：至少 3 个奖品且 20 枚金币为“默契”，有奖品为“协作”，其余为“抵达”。

生产生成已接入短绳公平段落：共同左绕、右绕、双人跳跃、同侧绕柱、同侧避球、前后配合和第三关双威胁。第二关包含独立身体高度绕行教学、石球与铁球两种单威胁变化；第三关保留这些教学并组合双威胁。每关首次完整教学循环不注入人为无解宽墙，避免必需内容被安全回退吞掉，后续无解候选仍回退安全段。每段用实际 road_run 固定步验证双方原始键盘轴值（每轴 -1/0/1）、奖励领取、预警与中央出口，独立断言禁止比例方向；出口只允许一个固定步以内的正常按键残差。缓存键包含完整段落布局、难度及关号，不再使用旧 11 米证书或整关固定右侧走廊。路线控制器仅用于生成验证和测试，不替玩家操作。当前内容返工及证据见 [t06 报告](docs/SHORT_ROPE_T06_REPORT.md)；[t05 报告](docs/SHORT_ROPE_T05_REPORT.md) 保留为此前历史记录。

双方地面中心最大间距 7.33 米（生产道路专用配置，历史白盒仍为 11 米），包含前后差；碰撞半径 0.6 米。接近 85% 连接长度时连线变金色。跳跃不强迫队友起跳，不增加地面连接长度。跳跃初速 12 米/秒、重力 40 米/秒²，最高 1.8 米、0.30 秒到顶、0.60 秒腾空（试玩初值）。高货箱 3 米，高于跳跃最高高度，须绕行。任意一人触碰危险且团队无护盾/无敌时共同失败；重试恢复双方合法地面状态。

绳索由独立模块 `scripts/rope_solver.gd` 求解。连线长度按贴地绕障路径计算（直线、切线和柱面弧段之和），不再只看两人直线间距；绳索挂点离脚底 1.4 米并随各自跳跃抬升，绳段在障碍占地范围内全部高过顶部才能从上方越过，否则挂住（5 米高柱无法越过）。绳长保持固定硬上限；腾空越过矮柱时提前预留落下后的绕障长度，可能在空中限制水平推进，下降照常进行。此类纯预留停滞不计失败时间，落下后真实接触且前向受阻才计时。绳索离开柱面后要离开超过 2.5 厘米或持续 0.1 秒不再压回才算解除，相切处的微小抖动不会反复挂上、脱开。两人分侧通过高柱时绳索挂在柱子上，接触环亮起；路径用尽后道路自动推进停住，连线与接触环转红并显示受阻计时。持续受阻 0.8 秒共同失败。受阻后一人向后退并从柱子后方绕到队友一侧可以解围：解绕期间计时暂停，绳索完全离开柱子后计时清零，推进在 0.5 秒内恢复全速。只向柱子靠拢能缩短路径、推迟受阻，但两人仍在两侧时最终还是会受阻。没有柱子接触的普通拉紧只限制移动，不计时也不失败。首轮绳索不含弹性、摆荡、松弛下垂和打结仿真，以上数值均为试玩初值。

t04 追加摆动巨锤、塌陷地板和错峰蒸汽的独立教学，均保留稳定同侧旁路。巨锤的锤头、旋转柄、支架和完整摆动包络参与检测；抬起后提供 4.2 秒共同通行窗口。塌陷板首次地面踩踏启动裂纹和双人退出宽限，塌后成为真实缺口，绳索不承重。蒸汽显示预警、升压、喷射、消退，实际绳段跨越喷口也会失败，消退结束无伤害。保留 t01 最终速度与动画参数。专项入口 `tests/obstacle_expansion_t04.gd`，实际证据与验收边界见 [t04 实施报告](docs/OBSTACLE_EXPANSION_T04_REPORT.md)。

## 危险与应对

各关按配置逐步加入危险，所有飞行物都是危险，不能拾取。角色碰撞体高度 2.9 米，危险底部与顶部均参与连续碰撞。

| 危险 | 危险高度 / 地面尺寸（米） | 应对 |
| --- | --- | --- |
| 高货箱 | 0–3.0 / 4×3.25 | 左右绕行 |
| 高柱 | 0–5.0 / 直径 1.2 圆柱 | 两人从同一侧绕行；分侧通过会让绳索绕柱 |
| 低栏 | 0–0.6 / 4×0.6 | 跳跃或绕行 |
| 固定地刺 | 0–0.5 / 4×0.6 | 跳跃或绕行，起跳与落地位置也须安全 |
| 活动地刺 | 0–0.8 / 4×0.6 | 跳跃、绕行或利用收回窗口 |
| 高位扫描束 | 1.3–2.5 / 4×1.2 | 四向绕避或安全时窗，不要求低姿态 |
| 低位迎面飞行物 | 0–0.5 / 2.8×1.2 | 独立跳跃或共同绕行 |
| 身体高度迎面飞行物 | 0.9–1.9 / 2.8×1.2 | 主要共同绕行；触碰绳段也会失败 |
| 石球 | 直径 4.5 / 球体 | 两人同侧避让；5 米/秒迎面运动 |
| 铁球 | 直径 4.0 / 球体 | 两人同侧避让；5.2 米/秒迎面运动 |
| 独立高速火箭 | 0.9–1.9 / 2×3.2 | 18 米/秒迎面运动；两人同侧避让，实际绳段命中同样失败 |

活动地刺和扫描束每 4 秒一周期：按难度预警 1–1.5 秒、危险 1.5 秒，其余时间安全。地刺伸出/回落各 0.25 秒。生产飞行物从前方持续可见并迎面接近，低位 9 米/秒、身体高度 11 米/秒。迎面预警按当前实际相对前向速度计算预计碰撞时间（TTC），提前量取难度配置与共同换边时间加 0.35 秒余量的较大值；普通初值约 2 秒。预警保存相对速度、TTC、换边时间与轨迹证据，锁定后不追踪玩家改道。模型、地面阴影和轨迹提示使用同一运动位置，角色与实际绕障绳段均做连续检测。历史横向飞行夹具仍可运行，不参与新的生产生成。

两种球复用同一机制及按类型回收的节点池，球体模型、碰撞半径与滚动路程同源，外观分别为粗糙石质与金属条带。球的接触圆随运动更新，绳索保存连续绕行侧，真实路径、张力和受阻反馈随之变化。绳长耗尽时球的运动驱动停在最后合法位置，不把角色强行拉过球；真实接触且约束耗尽持续约 0.8 秒共同失败。仅左右分侧、无接触不会失败；及时后撤可解围，能否解围仍取决于剩余前后空间，优先在预警时共同换边。绳索接触按实际高度区间内的最大球截面保守求解，并为跳跃全过程的最大截面预留长度；预留本身不伪造接触或单独累计失败。当前为平面切线/弧段及有界运动驱动，不含球质量、完整三维球面滑绳、弹性、摆荡或打结物理。

动态威胁专项：`tests/short_rope_t03_headless.gd`，证据见 [t03 实施与验证报告](docs/SHORT_ROPE_T03_REPORT.md)。当前组合生成与跨段回放见 t05；t03 仍作为动态威胁机制的回归入口。

障碍历史专项及动态高度返工见 [障碍与动作反馈报告](docs/OBSTACLES_REPORT.md)；当前生产连续碰撞夹具使用 `tests/endless_collision.gd`，文件名保留历史命名，不表示仍为无限关卡。

George / Leela 复用已有 CC0 骨骼资源，播放 Idle、Run、Jump、HitRecieve_1、Death 及基础过渡。阴影保持在地面并随高度缩小，连线三维端点跟随角色。地面规则与显示分离，20 地面单位为一米。
