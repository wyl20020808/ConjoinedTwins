# 共生连线 · 双人归航 Demo

两台机甲沿山路纵深自动前进，默认在同一键盘上合作避障；开始页也提供远程双人联机。没有 AI 控制或自动接管。跑动中是固定纵深镜头，不旋转、不晃动、不突然变焦；只有失败时进入失败演出：撞击推近到出事角色，坠落时镜头跟到崖外或缺口上方看角色掉进云海（撞击 1.6 秒、坠落 2.6 秒），演出结束才弹失败面板，期间空格/回车不会误触重试，R 可直接重试。

**Windows 启动：双击 `启动归航Demo.cmd`。** 或用 Godot 4.7.1 打开 `project.godot`，运行 `scenes/road_demo.tscn`。Agent 不自动打开游戏。

Windows 渲染：`project.godot` 设置 `rendering/gl_compatibility/driver.windows="opengl3_angle"`，Compatibility 渲染在 Windows 上经 ANGLE（Direct3D 11）运行。原因：Godot 4.7.1 原生 OpenGL 3.3 在本机 NVIDIA 610.88 驱动下运行约 1–6 分钟会在 `RasterizerSceneGLES3::render_scene` 内崩溃（signal 11）；同一自动试玩脚本经 ANGLE 或 Vulkan 运行未复现。Web、macOS、iOS 不受此设置影响。

## 操作与规则

| 按键 | 行为 |
| --- | --- |
| WASD | 青色 01 四向移动；W 向前、S 向后 |
| 空格 | 01 跳跃 |
| 方向键 | 橙色 02 四向移动；上向前、下向后 |
| 回车 | 02 跳跃 |
| 空格 / 回车 / 开始按钮 | 开始页或失败页启动共同出发，不附带跳跃 |
| Esc | 暂停 / 继续 |
| R | 两人共同回到起点 |

没有趴下、爬行或二段跳。跳跃按下触发，长按不会连续起跳；落地前约 0.10 秒内按下会在落地后立即起跳，更早的按键作废。开始、暂停恢复及重试会屏蔽仍按住的旧输入，请松开后重新按下。

道路自动推进，共三关；开始页选择简单/普通/困难，默认普通。双方四向手动移动速度 19 米/秒，斜向归一化；跑动动画按关速调整。两人各在推进中心前后 ±5 米内调节，实际路径受 7.33 米绳索约束。可见路面宽约 32.6 米，角色中心横向边界 ±16 米，越界会坠落。坠落救援：一人踩空而队友稳稳站在地面时，踩空者挂在崖边绳下、世界冻结；队友狂按自己的跳跃键（01 空格、02 回车、触屏点右半屏）拉人，踩空者按键效果减半，进度持续回落，3 秒内拉不满则共同坠落。救援期间救援者面向坠落者后仰、双手交替收绳（`RopePull`），坠落者双手交替攀绳、双脚蹬崖壁（`Climb`），绳子两端系在两人手上，按键越快动作越快；动画由 `tools/blender/make_rescue_anims.py` 在 Blender 中基于原角色骨架生成，导出为 `assets/humans/rescue_ropepull.glb`、`rescue_climb.glb`，专项检查 `tests/rescue_animation.gd`。拉满后有 0.6 秒爬上动画（救援者拉绳、踩空者翻上崖沿，世界仍冻结），随后站到队友附近、离坑沿留有余量且前方 1 秒推进路程内仍有支撑的落脚点，并获得 1 秒无敌；救起前按住的方向键须先松开（或 0.6 秒后）才重新生效。所需频率简单/普通/困难约 4/5.5/7 次每秒，同关每多救一次提高 15%；队友腾空或两人同时踩空仍直接失败。专项检查 `tests/fall_rescue.gd`，设计记录见 [玩法扩展路线图](docs/GAMEPLAY_ROADMAP.md)。路面约为绳长四倍宽，两人分开绕行时会被绳索拉住。原主障碍开口保持原 10.5 米路面的合法通道，新增宽度由巨岩补齐，摆锤和矿车外侧也封住，不能从加宽路面绕过。两人身体互不穿透（中心间距 ≥1.2 米），只削减朝对方靠近的位移，不推动静止队友。

三关随机池新增“独木窄桥”（每关两次）：两侧断崖贯穿整个路面，只留 2.2 米宽桥面、长 22 米，扣除碰撞半径后两人无法并排，必须一前一后单列通过；站在桥面上横向移动速度降为 35%，松开横向键会自动回正桥中线；桥长超过最高关速下的最大跳程，不能并排跳过。断崖缺口改为真正的镂空：缺口处路基隐藏，岩壁下方是与路外相同的云海；碎裂石板为琥珀色裂纹板。专项检查 `tests/narrow_bridge.gd`。

画面不再显示任何红黄警告：预警文字、落点框、飞行轨迹线、弹道走廊、发射标记、锤击区、缺口警戒条与预警带、尖刺/火箭半透明包络和碎裂板闪烁全部隐藏，预警音效也已去掉，只保留道具本身；判定和预警时长逻辑不变。飞行物明显加快：低空飞行物 32 米/秒、飞行体 48 米/秒、火箭 75 米/秒（教学关低空飞行物 21 米/秒），石球/铁球不变；三档道路推进速度提高到 14/16.5/18.5 米/秒。

巨岩（cargo）不再碰到即死：它是实心阻挡，人被挡住时可以贴边滑动，世界照常推进；被挡住的人会被留在推进中心后方，落后超过后方边界 7 米（被挤出画面）才判失败“被巨岩卡住挤出画面”。被卡住时向侧面让开即可追回。专项检查 `tests/cargo_squeeze.gd`。

地貌每 72 米轮换：石板山脊、松林（青苔路面、崖边松树灌木）、遗迹回廊（残柱石基、火把、旗帜）、赤岩荒脊（红褐岩面、风化巨石、枯树）。装饰全部在路沿外，不影响碰撞。

本地双人分别使用上表按键。开始/暂停/失败界面按 M 切换单人模式：02 由人机（`scripts/road_buddy_ai.gd`）控制，沿生成器验证过的路线跟随，但断崖前约 40% 概率犹豫不跳、掉下去等待救援（玩家连按空格拉人，人机也会连按），平时偶尔晚跳；单人时 01 可用 WASD 或方向键、空格或回车，按 F 让人机在下一处断崖必定失误，方便测试救援。联机每台设备控制分配的一个角色，可用 WASD 或方向键、空格或回车。触屏左半屏摇杆、右半屏跳跃：本地控制 01，联机控制分配角色；不是同一触屏设备双人操作。

各关速度为所选难度基础速度 × 1.00 / 1.08 / 1.16；简单/普通/困难基础速度为 12.5/14.75/16.5 米每秒；终点距离等于关速 ×100 秒。普通难度为 1475 / 1593 / 1711 米。回撤、受阻会延长实际时间，不设置时间失败。配置见 `scripts/road_levels.gd`。两人存活且地面位置都越过终点才结算；结算后先松开旧键，01 按空格、02 按回车分别确认，两人均确认后进入下一关；第三关确认后显示总成绩。结算期间 R 不重新领取奖励。

金币每个实例 +10 分；合作奖品每个实例 +100 分，前两关双方共同到位，第三关需角色中心分别进入互不重叠的前后光圈（角色可交换）。奖励按稳定实例编号记录，两人同时接触、跨帧接触和节点槽复用不重复计分。团队护盾最多一个，吸收一次角色危险伤害，提供 1 秒团队无敌；满盾时不会拾取叠加。吸收过的同一稳定碰撞事件不能再次消耗新护盾，无敌到期后仍在该危险中会失败。绳段命中、绕柱几何受阻和滚球带绳不受护盾保护；免伤也不允许穿过高货箱或高柱。

暂停冻结推进、跳跃、奖励、危险和无敌计时，保留接触以便原位继续；恢复屏蔽旧输入。R 整关重试当前关，关号保留但换新种子（联机两端同步派生），本关金币、奖品、护盾和碰撞去重清零，已完成关成绩保留，因此失败不能累计刷分。重新开始三关清空全部成绩。

存档点（试玩初值）：起点和此后每个段落入口各尝试存档一次；两人贴地站稳、绳未挂障碍，且直行走廊前方 1 秒关速路程（另加身体余量）内无固定危险、前方 2.5 秒内无移动危险时保存完整对局快照，入口不安全则在本段内顺延。失败页空格/回车（触屏主按钮）从最近存档点继续：地图、障碍相位、机关进度与存档时完全一致，存档之后已生成的段落按记录原样重装，不重新随机；金币、奖品、护盾回到存档时刻，并给 1 秒无敌；失败次数照常累计。联机两端同帧执行恢复，状态指纹保持一致。headless 夹具 `tests/checkpoint.gd` 显示普通第 1 关约每 1.4 段一个存档，困难第 3 关约每 1.7 段一个、最大间距约 4.9 段；可见手感待试玩。评价规则：至少 3 个奖品且 20 枚金币为“默契”，有奖品为“协作”，其余为“抵达”。

生产生成用实际 road_run 固定步验证双方原始键盘轴值（每轴 -1/0/1）、奖励、预警与出口，候选未通过时尝试其他布局或安全回退。缓存绑定布局、难度、关号及源码；路线控制器仅用于生成验证和测试，不替玩家操作。不再依赖固定右侧走廊或固定教学循环。本轮合法键盘路线见 [基线报告](docs/BASELINE_T01_REPORT.md)；[t06 报告](docs/SHORT_ROPE_T06_REPORT.md) 等记录保留为历史证据。

双方地面中心最大间距 7.33 米（生产道路专用配置，历史白盒仍为 11 米），包含前后差；碰撞半径 0.6 米。接近 85% 连接长度时连线变金色。跳跃不强迫队友起跳，不增加地面连接长度。跳跃初速 12 米/秒、重力 40 米/秒²，最高 1.8 米、0.30 秒到顶、0.60 秒腾空（试玩初值）。高货箱 3 米，高于跳跃最高高度，须绕行。任意一人触碰危险且团队无护盾/无敌时共同失败；重试恢复双方合法地面状态。

绳索由独立模块 `scripts/rope_solver.gd` 求解。连线长度按贴地绕障路径计算（直线、切线和柱面弧段之和），不再只看两人直线间距；绳索挂点离脚底 1.4 米并随各自跳跃抬升，绳段在障碍占地范围内全部高过顶部才能从上方越过，否则挂住（5 米高柱无法越过）。绳长保持固定硬上限；腾空越过矮柱时提前预留落下后的绕障长度，可能在空中限制水平推进，下降照常进行。此类纯预留停滞不计失败时间，落下后真实接触且前向受阻才计时。绳索离开柱面后要离开超过 2.5 厘米或持续 0.1 秒不再压回才算解除，相切处的微小抖动不会反复挂上、脱开。两人分侧通过高柱时绳索挂在柱子上，接触环亮起；路径用尽后道路自动推进停住，连线与接触环转红并显示受阻计时。持续受阻 0.8 秒共同失败。受阻后一人向后退并从柱子后方绕到队友一侧可以解围：解绕期间计时暂停，绳索完全离开柱子后计时清零，推进在 0.5 秒内恢复全速。只向柱子靠拢能缩短路径、推迟受阻，但两人仍在两侧时最终还是会受阻。没有柱子接触的普通拉紧只限制移动，不计时也不失败。画面麻绳具有下垂和摆动，绕障时贴合真实求解路径；碰撞仍使用上述路径与高度，不把视觉下垂作为新的碰撞或承重物理。没有弹性及打结物理，以上数值均为试玩初值。

摆锤的锤头、旋转柄、支架和完整摆动包络参与检测；当前为龙门架单摆，不能沿用历史“抬起后 4.2 秒窗口”。塌陷板首次地面踩踏启动裂纹和双人退出宽限，塌后成为真实缺口。蒸汽实际绳段跨越喷口也会失败。历史专项 `tests/obstacle_expansion_t04.gd` 及 [t04 报告](docs/OBSTACLE_EXPANSION_T04_REPORT.md) 原样保留。

## 危险与应对

各关按配置逐步加入危险，所有飞行物都是危险，不能拾取。角色碰撞体高度 2.9 米，危险底部与顶部均参与连续碰撞。

| 危险 | 危险高度 / 地面尺寸（米） | 应对 |
| --- | --- | --- |
| 高货箱 | 0–3.0 / 4×3.25 | 左右绕行 |
| 高柱 | 0–5.0 / 直径 1.2 圆柱 | 两人从同一侧绕行；分侧通过会让绳索绕柱 |
| 低栏 | 0–0.6 / 4×0.6 | 跳跃或绕行 |
| 固定地刺 | 0–0.5 / 4×0.6 | 跳跃或绕行，起跳与落地位置也须安全 |
| 活动地刺 | 0–0.8 / 4×0.6 | 跳跃、绕行或利用收回窗口 |
| 高位扫描束 | 1.3–2.5 / 4×1.2 | 四向绕避或安全时窗，不要求低姿态 |
| 低位迎面飞行物 | 0–0.5 / 2.8×1.2 | 独立跳跃或共同绕行 |
| 身体高度迎面飞行物 | 0.9–1.9 / 2.8×1.2 | 主要共同绕行；触碰绳段也会失败 |
| 石球 | 直径 4.5 / 球体 | 两人同侧避让；5 米/秒迎面运动 |
| 铁球 | 直径 4.0 / 球体 | 两人同侧避让；5.2 米/秒迎面运动 |
| 独立高速火箭 | 0.9–1.9 / 2×3.2 | 18 米/秒迎面运动；两人同侧避让，实际绳段命中同样失败 |

活动地刺和扫描束每 4 秒一周期：按难度预警 1–1.5 秒、危险 1.5 秒，其余时间安全。地刺伸出/回落各 0.25 秒。生产飞行物从前方持续可见并迎面接近，低位 9 米/秒、身体高度 11 米/秒。迎面预警按当前实际相对前向速度计算预计碰撞时间（TTC），提前量取难度配置与共同换边时间加 0.35 秒余量的较大值；普通初值约 2 秒。预警保存相对速度、TTC、换边时间与轨迹证据，锁定后不追踪玩家改道。模型、地面阴影和轨迹提示使用同一运动位置，角色与实际绕障绳段均做连续检测。历史横向飞行夹具仍可运行，不参与新的生产生成。

两种球复用同一机制及按类型回收的节点池，球体模型、碰撞半径与滚动路程同源，外观分别为粗糙石质与金属条带。球的接触圆随运动更新，绳索保存连续绕行侧，真实路径、张力和受阻反馈随之变化。绳长耗尽时球的运动驱动停在最后合法位置，不把角色强行拉过球；真实接触且约束耗尽持续约 0.8 秒共同失败。仅左右分侧、无接触不会失败；及时后撤可解围，能否解围仍取决于剩余前后空间，优先在预警时共同换边。绳索接触按实际高度区间内的最大球截面保守求解，并为跳跃全过程的最大截面预留长度；预留本身不伪造接触或单独累计失败。当前为平面切线/弧段及有界运动驱动，不含球质量、完整三维球面滑绳、弹性、摆荡或打结物理。
